## 📊 个人节律

### 双相周期（最重要变量）

| 周期       | 状态                   | 适合任务                             |
| ---------- | ---------------------- | ------------------------------------ |
| **躁狂期** | 高能量、创意爆发、自信 | 创意工作、开源开发、写作、设计       |
| **抑郁期** | 低能量、机械、自省     | 维护性任务、数据整理、复盘、简单编码 |
| **过渡期** | 不稳定                 | 轻量任务、休息                       |

**特点**: 周期以周或月为单位，而非日内。需要识别当前所处周期并相应调整任务类型。

### 周内能量分布

| 日期     | 能量 | 说明                     |
| -------- | ---- | ------------------------ |
| **周一** | 高   | 周末休息后，想快速投入   |
| **周二** | 中   | 开始积累                 |
| **周三** | 高   | 高强度科研日             |
| **周四** | 高   | 高强度科研日             |
| **周五** | 中   | 组会后略疲惫             |
| **周末** | —    | 陪伴伴侣，不评估工作能量 |

### 工作偏好

- **单任务深入**: 一次只做一件事
- **厌恶打断**: 需要整块时间保护
- **Yak Shaving**: 持续威胁，需要「分支两层限制」
- **信息获取**: 需要制定规范，目前信息输入不足
