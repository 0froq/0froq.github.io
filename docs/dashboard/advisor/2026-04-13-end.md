### 2. 湖泊 ID 匹配调研 ✅ **关键进展**

**核心发现：**

- GLAST 数据集包含 `Hylak_id` 字段
- 该字段可与 **HydroLAKES v1.0** 的 ID 直接对应
- 这意味着可以通过 HydroLAKES 的变量来筛选湖泊

**HydroLAKES 信息：**

- 最小湖泊面积：10 公顷
- 总计：140 万个湖泊
- GLAST 中 36% 湖泊位于北极区域（这解释了为什么全球平均值偏低）

**意义：**

- 解决了从 9 万个湖泊中筛选目标湖泊的路径问题
- 可以利用 HydroLAKES 的元数据（面积、位置等）进行筛选
- 为数据融合方案（GLAST + 其他数据源）奠定了基础
