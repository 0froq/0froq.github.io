## 内容

这是一篇持续更新的公开账本，不是版本发布。
2024 年起的 Sponsorship Forwarding：赞助他本人与常用工具，
再经 Open Collective 转到依赖、基础设施和具体贡献者。
资金流水公开：https://opencollective.com/antfu

2026 年已转发的名字里，和 froQ 现用栈直接相关的有：

- Leo Liang（yuyinws）\$500：oxc-inspector 捐给 Vite DevTools，
  继续维护，降低 Oxc 迁移的可见成本
- Kerman（kermanx）\$250：维护 Slidev，并做 reactive-vscode
- jinghaihan \$250：vsxpub，以及面向流式输出的
  vue-stream-markdown
- Alec Lloyd Probert \$250：参与 npmx.dev，并维护 Vue Data UI

2025 年名单更长，覆盖 UnoCSS（zyyv）、Vite（bluwy）、
VitePress（brc-dd）、VueUse、Vapor（edison1105 / LittleSound）、
Vue Router / Pinia（posva）、unplugin（sxzz）、
alien-signals（johnsoncodehk）。
常驻项仍是 e18e、esm.sh、pnpm、Iconify。

文中明确：这些转发解决不了开源可持续性，
只是让被依赖、但不在聚光灯下的工作更可见。

## 对 froQ 的影响

这不是要现在去赞助，也不是要改 blog / poim 的依赖。
论文仍是硬任务；开源贡献在完整稿之前不主推。

有用的是名单本身。
「论文完成后 90 天内首个 PR、优先 Vue 生态」如果仍成立，
第一刀不必默认打进 vuejs/core。
2026 年被点名的仓库更小、更具体：
Vite DevTools / oxc-inspector、Slidev、vue-stream-markdown。
这些仓库的维护者已经被 Antfu 基金标成「生态真正在转的人」。
