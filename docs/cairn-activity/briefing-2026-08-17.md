# 🧿 早报 · 8月17日

你昨天最值得看的不是又多了一个工具，而是把 Bot Mode、Kanban
与 Multica 的边界收束清楚了：前者承接成员与会话，Kanban 承接任务
状态、依赖、重试与审计；两者结合，才是 Multica 的本地替代候选。

技术追踪整体安静。VoidZero 的 7 月回顾值得留一眼：Vite 8 使用量增长，
Oxlint 的 type-aware linting 已稳定，Rolldown 在大构建峰值内存上报约
21% 的下降；它更像生态进展汇总，暂时不构成迁移动作。

## Tracker

- **Vite 8 + Rolldown 迁移实操**：一份中型 Vue 生产应用的迁移记录指出
  三类具体兼容变更：`build.rollupOptions` 改为 `rolldownOptions`、
  CJS interop，以及 Yarn PnP；可留作你未来处理构建链升级时的案例。
- **尚古系列可变 CJK 字体**：基于思源系列的传承字形可变字体项目，
  8 月 8 日有更新；它是排版兴趣线上的新项目，而非需要立刻切换的资产。
- **Neovim 0.12 回顾**：补充了 `vim.pack`、LSP 扩展、原生补全和 Lua API
  的具体脉络；版本本身已知，这篇适合需要时回看。
- **VoidZero 7 月生态回顾**：ViteConf 将于 10 月 15 日线上举行；
  Vitest 5.0.0-beta.7 以及 Oxlint 的 type-aware linting 是其中较实在的进展。
- **研究线**：湖泊相关检索没有发现足以新增记录的论文；部分结果虽与
  水体有关，但偏冰川湖灾害或河流流量，和你的当前湖泊增温方向不够贴合。
