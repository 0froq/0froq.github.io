原型：[prototype.html](./prototype.html)
（离线打开。首页是垂直剖面；文章是取出的样芯。）

## 主张

知识是沉积，站点是剖面。
Posts 和 Dashboard 只是地表；
六层 corpus 才是别人记住这座花园的理由。
层用深度色块说话，而不是用文件夹列表。

一句话：让 000–500 成为主视觉，而不是侧导航。

## 情境

- 第一次来的人应在一屏里感到「下面还有东西」。
- 作者要看见层的薄厚：Delirium 必须薄，
  Vigil 必须沉在底。
- 读长文时必须离开色带，换到样芯纸上。
  色块上排正文即失败。

## 结构

首页：左 72px 深度尺 + 右七层地层。
层从地表到 500 Vigil 垂直堆叠，
每层最低约 18vh（地表略矮，守夜略深）。
点地层进入对应阅读或目录。

| 页 | 形态 |
| --- | --- |
| 剖面首页 | 尺 + 七层色带 + 真实量级 |
| 取出的样芯 | 独立纸面，max 46rem |
| 层位目录 | 同一纸面，按深度列条目 |
| 气候条 | 地表天气 + board 文本 |

层色按物质，不按品牌色盘：
地表冷绿、解剖灰纸、摄入褐灰、
增生暖沙、腐败暗褐、谵妄砖、守夜石青。

## 排版

首页标题衬线 28px，说明 16px / 62ch。
样芯页衬线 34px 标题，正文按阅读列。
深度编号等宽、字距拉开。
中英术语保持原形
（`struc` / `ref` / VitePress）。

## 色彩

底 `#e7e2d6`；样芯纸 `#f4f0e6`。
深色把地层压成低饱和沉积，
而不是把浅色块简单反相。
`put` / `del` 浅色上用深墨，深色上改回浅墨，
避免对比不足。

## 交互

点地层即换视图（hash）。
剖面本身几乎无铬：没有卡片墙、没有 hero。
Dashboard 不是另一座建筑，
是剖面露出地面的气候条。

## 窄屏 / 无障碍

- 跳转「跳到剖面」。
- 800px 以下深度尺收成 28px 色刻度，
  隐藏刻度文字（`font-size: 0`），
  层名仍在地层标题里。
- 地层 `min-height` 放开，避免窄屏上
  七段色块撑出超长空卷。
- 色不单独表意：每层有编号 + 中文名 + 计数。
- `prefers-reduced-motion` 关掉过渡。

## VitePress 落地路径

这不是 shortcut 微调，是新首页壳：

1. 新组件（例如 `StrataHome.vue`）替换
   `ContentIndexGlobal.vue` 的主列，
   或作为 `home: true` 的另一种 layout。
2. 层计数从 `corpus.data.ts` 的 `layer` 聚合，
   禁止手写 22 / 18 / 26。
3. 表层天气读 `board.yml`：
   `active` 可有 `status`；
   `backlog` / `archive` 无 status。
4. 文章路由仍走 `ContentArticle.vue`，
   但必须换到样芯纸背景，
   不得把 `#content` 叠在地层色上。
5. corpus 层页可保留现有
   `corpus/Layout.vue`，
   仅把索引页改成垂直层位。

未选定前不要改 `PageContent.vue` 的路由分派。
先做一页可切换壳，喂真实 data loader。

## 成本 / 风险

- **成本中高。** 首页信息架构变了，
  旧的欢迎 / 最近落笔 / 项目卡要重新安放。
- **展览化。** 色带好看但拒人；
  必须保留自我陈述与最近落笔的入口，
  不能只剩地质学。
- **长文失败模式明确：**
  任何把段落排进地层色块的实现都算不合格。
- **层色会和纸纹背景打架。**
  `.site-shell` 的 lined-paper mask 在剖面上要关掉。
- **回滚难于页边。** 新壳一旦替换首页，
  旧 `ContentIndexGlobal` 要整页可切回。
