---
title: 字谷 Foundry
---

原型：[prototype.html](./prototype.html)
（几乎无铬。字号阶是结构，朱色只出现一处。）

## 主张

先排字，再排空间。
结构字体不超过三族：宋体正文、黑体导航、等宽元数据。
强调色一处朱。
没有第三种装饰字体，没有渐变，没有玻璃。

一句话：把排字纪律抽出来，可并进任何一案。

## 情境

- 长篇中文靠字距、行长、标点停顿，不靠卡片摘要。
- 英文术语保持原形。
- 首页可以像字样页（specimen），
  但目录和工单必须仍能扫。
- 作者对字体和命名的执念应落在系统里，
  而不是落在又一个 display 字体文件。

## 结构

单列 `52rem` 字样页。
底栏 sticky 跑马：在场、语言、状态。
无侧栏。元数据用定义列表和目录行，不用芯片墙。

| 页 | 形态 |
| --- | --- |
| 字样 | 巨大「于此。」+ 自我陈述 + 索引 dl |
| 成言 | 阅读列 38rem，首字下沉，标题阶 |
| 目录 | 六行层目录：编号 / 名 / 计数 |
| 工单 | 真正的表：状态 / 工作 / 说明 |

## 排版

字号阶（原型）：

- 显示：`clamp(4.2rem, 14vw, 9.5rem)`，行高 0.88
- 文章标题：`clamp(2rem, 5vw, 3.2rem)`
- 正文：20px / 1.7
- 元数据 / 导航：12–14px 无衬线，字距拉开

首字下沉只用于成言开头，不用于 corpus 碎片。
链接同色，悬停才朱。
Dashboard 用表，不用看板卡片——
空的 weekTheme 也是一种排版。

落地映射现有规则，不要新下载字体：

- 正文 → `font-serif`
- 导航 / 元数据 → `font-sans` + `font-mono`
- **删除或限制** `font-script` / `font-stylish`
  在结构位置的出现（首页现有 Ephesis / Caveat）

## 色彩

纸 `#f7f4ee` / 墨 `#12110f`。
朱 `#9c2b1d`（深色 `#e06a58`）只用于：
句读点、kicker、当前工单、悬停链接、焦点。
禁止把朱铺成色带。

## 交互

尽量少。切视图、切深浅色。
无命令面板、无 sticky 页边、无地图。
底栏在场是只读。

## 窄屏 / 无障碍

- 跳转「跳到正文」。
- 700px 以下 display 降到 3.4rem；
  索引 dl 与目录行改单列。
- 正文 18px。
- 表可横向溢出，但列少（三列），一般不必。
- 焦点描边用朱色 2px。
- 巨大标题必须是真正的 `<h1>`，
  供读屏和大纲，不能是装饰 div。

## VitePress 落地路径

字谷更像约束层，而不是新壳：

1. 收紧 `style.css` 与 Uno 的 type scale：
   正文、h1–h3、元数据三级即可。
2. 强调色收到一个 CSS 变量
   （现站链接是中性虚线，可把「一处朱」
   留给当前条 / 句读 / 焦点）。
3. 首页 `docs/index.md` 的 script / stylish 混用要裁决：
   保留一句手写，或删到三族。
4. Dashboard 可把任务改成表，
   仍读 `board.yml`，不改列语义。
5. 最便宜的用法：选定页边或岩芯之后，
   **把本表当作验收清单**，不单独落地。

## 成本 / 风险

- **成本低，作为主视觉不够。**
  结构几乎仍是现在的单列纸面。
- **display 不能套长标题。**
  「从零开始搭建博客网站（一）」
  用 9.5rem 会爆。只给「于此。」这类短词。
- **三族纪律会碰到现站五族字体。**
  这是有意做减法，要明确哪些展示字体退休。
- **过瘦。** 无页边时，批注和 ghost 只能回到浮层——
  那是现站已经在付的成本。
- **首字下沉与中文标点：**
  原型把「没」沉下去；
  落地要避免把引号或 markdown 标记当首字。
