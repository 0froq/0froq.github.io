从零开始搭建博客网站（一）

预备知识与安装。本站使用 VitePress——基于 Vue 3 和 Vite 的静态站点生成器，使用 UnoCSS 进行样式设计，托管在 GitHub Pages 上。正文中统一使用 TypeScript 行文。
