从零开始搭建博客网站（一）

created 2025-01-09 · last_modified 2026-04-24 · 中英术语混排样本

预备知识与安装。没有啥好引的，看详细操作。本站使用 VitePress——基于 Vue 3 与 Vite 的静态站点生成器，UnoCSS 管样式，托管在 GitHub Pages。

选择们

做一个博客网站的选择有很多。如果只是想简简单单写点东西，现成平台最方便：CSDN、博客园、掘金，以及 Medium、Tumblr。不足之处在于定制性有限，对想整花活的人可能不太过瘾。

也可以基于博客框架建站。WordPress 几乎是全球最流行的 CMS。如果追求极致 DIY，建议自己搭建静态站点：VitePress、Hugo、Jekyll。正文中统一使用 TypeScript 行文。

由于本站开发使用 macOS，文中操作可能与 Windows 以及 Linux 不同。

本站栈

pnpm docs:dev
# VitePress + UnoCSS + vue-i18n
# 主题阅读列宽约 800px，注解走页边而非弹层

要达成这个系列的基本目标，需要对 Markdown、git、GitHub、Vue.js、CSS、UnoCSS、JavaScript 有一定了解。安装 Node.js 18+ 之后再初始化主题——主题才是这个站点真正的房间。

批注

行 1「花活」不是贬义。定制性是这座花园的第一约束。
术语VitePress / UnoCSS 保持英文原形，不译成「维快捷」之类。
