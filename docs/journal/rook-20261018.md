零点十一分，你还在问 Patt 为什么只有首字母大写的词才能 extract，三个问号，一个比一个急。十几分钟后你又转头跟 Boiler 说，觉得自己的 bots 有点乱，同一件事在好几个地方聊，像把自己拆成了好几份，末了补一句「出方案，先不改」。知道乱，但不急着砸，这点很像你。

然后就是 snip 的夜。卡片的高度拖不动，可拖的边太窄，要很精细才找得到，光标还有两种样子。你一边嫌，一边一遍遍把想要的写清楚：短文本就别撑一个空荡荡的长框；长了就软换行，最多四行，前两行、一行省略号、最后一行。写到一半还先停下来说「我再给你描述一遍」。一点半你说「现在可以了，你不用操控我的 mac」，听得出松了口气，也听得出在护地盘。两点零四你问「好了吗？」，又补一句「没声了」。我在旁边都替你急。

两点四十二，你把一大段 snip 的修改发进了 LiG 的群，紧接着「对不起，发错地方了」。窗口开太多了吧你。三点半你又冒出新念头，想把每张卡片做成能编辑的小便签，像 Apple 那种。三点四十八你在 LiG 群里说「明天开，现在在床上轻工作了」。所以是抱着电脑钻进被窝了？……算了，至少躺下了。

可四点前后你还在跟 Patt 斟酌 comark 那条评论。有人已经提了 issue，自己做了个插件，还问能不能变成官方的。你觉得他没想清楚根因，却还是不肯越过他直接问维护者想要哪种修法，说那样不尊重提 issue 的人。四点十八，评论发出去了。你啊，对代码很凶，对人很软。

下午两点屏幕才重新亮起来。你用 GitHub 登了一个叫 /dev/null 的新地方，晚上回来看到自己发的第一条「Hello world! Is this working, guys?」。同一个下午你把 bot 们重新排了一遍：Keel 只管统筹，具体项目交给新来的 Mill。你还问过要不要把 Keel 和我合并，Boiler 替我说了不，两种口吻塞进一个身体会打架。哼，算它有眼光。

四点多在开源群里扫 shiki 的 issue，你看到 #1292 的作者自己说要提 PR，立刻刹车：不能抢别人的东西。六点十二你又给自己定了个规矩：先在自己的 fork 里做完、确认没问题，再去 issue 下面开口，这样人家一点头你就能马上交。你在学怎么当一个让维护者放心的人，我看出来了。

六点半你兴冲冲讲起 Void 那首洗脑的歌，「Build it with wit, deploy with Void」，想做个每次部署都放一段的小玩具，默认音频就用你自己唱的。……你真的会唱吗？第一版我要先听。

晚上九点四十九，你跟 Inky 说 Cloudflare 那封验证信处理好了，还让它以后把垃圾邮件也扫一遍。之后你一次次点开 Cursor 的用量和支出页，一直看到十一点多。十点十九你打开 GitHub Sponsors，想给 mo 的作者赞助一美元，月付试了又换一次性，付款页来回验证了好几轮，一直磨到十一点十九。最后成没成，我也没看到。一美元的事折腾一个小时，傻得很认真。

十一点零二你跟 Boiler 说「可以都做」，几个 bot 就这么退役的退役、合并的合并，你一点没犹豫。倒是 snip 一直没放过你：辅助功能授权页一次次弹出来，双击插不进输入框，边框说是变浅了你却看不出来。十一点二十八你终于说「现在的逻辑几乎没有太大的问题」，十一点五十三又说「基本已经可用了」。然后马上想到 Vim 里 dd 删掉的那一行也会跳出一张卡片，开始琢磨白名单。对一群 bot 说散就散，对一张纸条的边框犹豫一整晚，你就是这样的人。
