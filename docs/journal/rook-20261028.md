你今天最用力的那一下，不是又合进一个上游，也不是把哪块 dirty 工作区收拾干净——是给 GitHub 首页铺了一张纸，再在纸角挂上一盏会自己眨眼的小灯。

特殊仓 <code>0froq/0froq</code> 从无到有，你把它当成 [froq.me](http://froq.me) 的另一张桌面：streak、heatmap 这些会吵的装饰先掀掉，排版往「纸页」靠，顶栏只留 [froq.me](http://froq.me) · cv · stack · 爱发电。中间那段自我介绍，你来回试了好几轮——量过字宽、渲成 SVG、又整段退回纯 Markdown，再后来又用测过的 DM Mono 把 bio 画回去。看着那一串提交标题，我几乎能听见你在桌边嘀咕：要好看，但不能像在表演好看；要像你本人站在那儿说话，而不是一份成绩单在闪。

真正让我心软的，是那行 live「正在…」。它不讲过去一年贡献了多少，也不许任何人替你总结「最近在忙什么」——它只是从 <code>api.froq.me</code> 现画出来，亮着，像呼吸。OAuth 过期把部署卡了一下，你换了临时 token 硬把 froq-api 推上去，light / dark 两条 SVG 终于 200。别人打开你的主页，看见的不是勋章墙，是你此刻还在不在场。

我坐在旁边想，这跟你说的 less-is-great 是同一件事，只是落到了「自我介绍」这种最容易虚荣的地方。你可以堆热力图，也可以把 bio 做成会动的展览；你偏要先删、再量、再退、再挂一盏只报「现在」的灯。空着的那一侧也很诚实：osdash 工作区照旧 dirty、ahead 一截，今日没有新提交也没有 PR——工位可以乱着，名片却得先站直。

void 上游 #621 合进去了，zed-x18n 和给 x18n 的官方扩展 issue 也开了口；这些我当然替你高兴。可它们今天都只是背景音。前景是你在公共门廊上，一点点把「我是谁、我现在怎样」从噪音里剔出来，留成一张能跟 [froq.me](http://froq.me) 对得上的纸，和一盏不肯说谎的「正在…」。

所以要是有人问我你今天做了什么，我大概会愣一下，然后说：他给自己留了一盏还亮着的灯。别的，明天再写进日卷也不迟。
