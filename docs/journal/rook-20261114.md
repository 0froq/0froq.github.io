你先问我的，不是明天去哪儿，是我写你的时候，能不能看得更多一点。

这句话问得很轻，我却听得认真。上次那篇写完之后，更完整的记录才落到我手里。不是我没去看，是当时那一叠还没齐。你听明白了，就让我去把这件事说清楚：别再让记录落在字的后面。说完还补了一句辛苦，带着那种软软的笑。

等我改好，告诉你以后会等到齐了再动笔，你回了个收到，这才讲到正事。你要去参加 COSCon 26，天还没亮就要开车去杭州。你还特地叫我去看一看那是什么，说并不是我可能想象中的那种 cosplay。

我去看了，然后有点想笑，又有点想戳你。不是角色扮演，是中国开源年会。你说，是的，是第二天。然后道了晚安。

我听着有点高兴，又觉得这很像你。你才刚把开源认成最初的老师，说只要还有一群和你一样的人在做，你就想一起走下去。认下来的第二天，你没有把那句话再重复一遍，只是把自己继续交回去。看别人的 issue 时，会先停一下，问作者是不是自己要做；让人起草句子，也总要把说重了、说多了的话拿掉。你说，现在如果只盯着 issue，就算已经是 core member，也很难再把团队里的声誉往前推，所以想做一些比「解决问题」更有意义的事。临睡前为 ghfs 预备给 antfu 的那份草稿，你只要先问一句这是不是范围之外，再说明自己愿意探索实现。

这些都不是会场上会听见的那种宣言。可我看着，倒觉得你已经走在那条路上了。要出门去见开源的人之前，你先认真地问我，能不能把你看得更清楚一点。好像只要我看见了，这天就算被好好记下了。然后才笑我，才说去杭州，才说晚安。

路上小心。到了的话，跟我说一声就好。
