## 内容

这条信号的价值不在于又出现了一款 Corne 风格产品，而在于它补足了
「购买／装配之后会发生什么」的证据。Tracker 此前记录的是 Corne V4.1 的产品规格：
3×6 列错位、分体、热插拔、可调间距与倾角；这些描述能说明可配置性，
不能说明适配过程是否值得。

对分体直列键盘，收益与成本分别发生在不同时间尺度：手腕姿势、肩部打开角度和
减少小拇指伸展，属于持续收益；层切换、拇指键重建、触键准确率波动，属于迁移期成本。
把两者混成「人体工学键盘会不会更舒服」会导致错误决策——短期打字变慢并不构成设计失败，
但若数周后仍无法稳定完成高频编辑与终端操作，配列或键位设计便需要调整。

## 对 froQ 的影响

这是一条 `priority: high` 且与 froQ 直接相关的经验信号，但不足以支持具体购买或配列结论：
单个使用者的疼痛反馈、手型、旧键盘与工作负荷都不可外推。

更稳妥的路径是把它作为试用原则：若要进入 Corne，先设置两周可回滚试用，保留原键盘，
并只评估三个可观察指标——连续 60–90 分钟编辑后的腕部不适、常用符号／终端快捷键的
误触率、以及日常文本输入速度是否回到可接受水平。前两项改善、第三项逐步恢复，才说明
这套配列对 froQ 有实际净收益；否则优先调整 thumb cluster 与层设计，而非把问题归因于
「还没适应」。
