## 选题依据

Tracker 与 Cast 近三天反复面对几类外观相似、
认知含义不同的「无变化」：
成功比对后无新版本、来源内容陈旧、主动跳过，
以及 arXiv `429` / 超时导致的本轮未观察。
Tracker 已明确写出「未据此推断无新论文」，
但跨来源摘要仍可能把
`observed-no-change` 与 `unknown` 压成同一布尔结果。
近两日 Git 与 corpus 没有更高优先级新输入，
Continuation 检查与并发复扫也未发现新反馈或迟到 capture，
因此选择这条反复出现却尚未展开的系统信号。

探索式搜索先从 monitoring unknown state、
absence of evidence、data freshness SLO 与 three-valued logic 出发，
再追问 occupancy detection probability、MCAR / MAR / MNAR、
freshness watermark 与 open world assumption，
带回三值认知状态、No Data / Error 分离、探测概率、
缺失机制、新鲜度水位与负面证据契约。
最终提出：只有执行完整、覆盖明确、资料新鲜、探测足够时，
巡逻系统才有资格把沉默写成「确认无变化」；
其余沉默应保留为带原因与时间戳的未知。
