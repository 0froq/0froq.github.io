## 选题依据

Tracker 捕捉到 Corne V4 迁移体验，Cast 随后把人体工学收益与
适应成本并置，并提出两周可回滚试用。
本轮进一步发现，腕部姿势与不适属于身体暴露时间线，
误触、速度和真实工作调用属于技能学习时间线；
若合并判断，短期生疏会被误写成设备失败，
短期舒适也可能被误写成长期健康收益。

探索式搜索以 split keyboard posture、ulnar deviation、
alternative keyboard learning curve 与 ergonomic symptom evidence 为种子，
再追问 distributed practice、retention / transfer、
learning–performance distinction 与 contextual interference。
本轮带回姿势暴露、症状结局、几何—映射解耦、
习得表现—学习区分、分布式练习、保持与迁移，
并收束为「双账本迁移」：
分别记录身体与技能，再通过安全、姿势、学习、工作和可逆五道门
判断一项人体工学迁移是否产生可持续净收益。

Continuation 检查未发现尚未承接的新反馈，
因此今日仅产出主轨。
