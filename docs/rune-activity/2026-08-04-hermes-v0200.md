## 来源
Tracker @ 2026-08-04 01:00 发现 Hermes Agent v2026.8.3（即 v0.20.0），
相对已记录的 v2026.7.30 / v0.19.1 的新版本。

## 内容
Hermes v0.20.0 代号 Herald，是功能密度极高的一次大版本。
自 v0.19.0 以来约 3,650 commits、1,400 个 PR、1,200 个 issue 关闭。

核心变化：
- 实时语音对话（流式 TTS、打断、设备端唤醒词、免提控制），
  覆盖 CLI、桌面端及所有音频网关平台。
- Agent-to-Agent（A2A）v1.0 协议，实现异构 agent 间标准通信。
- 签名 outbound webhooks，可向外部系统推送生命周期事件。
- 桌面端成为平台：artifacts 实时预览、插件 SDK（首个插件 Kanban）、
  快速入口窗口、多窗口。
- CLI 增强：`!` 直接执行 shell、`/init` 生成 AGENTS.md、`/diff`、`/context`、
  `/focus`、Ctrl+S 暂存草稿。
- 工具自愈：输出截断自动落盘、`patch` 检测已应用编辑、
  `write_file` 回读校验、搜索近失匹配提示。
- 默认工具迭代上限 90 → 500。

同时 Tracker 发现 Rolldown v1.2.2 与 Node.js v26.6.0 / v24.19.0，
均为常规维护更新，无架构级变化。

## 对 froQ 的影响
froQ 当前运行 Hermes 作为 agent 框架，v0.20.0 的以下特性
与现有工作流直接相关：
- `/init` 可自动生成或更新 AGENTS.md，
  与当前仓库的 AGENTS.md 维护方式形成互补或替代。
- `/context` 可查看 context window 占用，对调试长会话有用。
- 工具自愈与迭代上限提升，直接改善 cron 长任务稳定性。
- 语音与 A2A 属于能力扩展，若 froQ 有跨 agent 或免提需求可评估。

升级前建议先阅读迁移指南，确认配置兼容性；
Rolldown 与 Node.js 更新可随常规依赖升级处理。
