# Vigil

<ruby><rb>Vigil</rb><rt>watch</rt></ruby> 是存在证据层。

这里记录“我如何活着、如何选择、如何成为我”的锚点。它不要求转化为知识，也不要求服务项目。它的价值是证明某个时刻、某种判断、某种身份状态真实存在过。

## 放在这里的东西

- 私人但重要的生活片段
- 身份判断和价值选择
- 某个阶段的存在状态
- 不适合放进普通日志、但又不只是概念的东西
- 能够作为未来自我锚点的记录

## 与 200 / 300 的关系

`500` 可以和 `300` 相邻，但不等同于日志。  
`300` 问“发生了什么，以及现实如何改变计划”。  
`500` 问“这件事证明了我是什么样的人，或者我正在变成什么”。

当一个存在片段开始抽象出概念、判断或模型时，可以回流到 `200 Neoplasma`。
