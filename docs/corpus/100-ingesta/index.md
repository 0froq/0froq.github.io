# Ingesta

<ruby><rb>Ingesta</rb><rt>intake</rt></ruby> 是外部资料登记簿。

这里记录稳定、可回访、可引用的外部来源，而不是所有日常刺激。它可以非常原始，甚至只是一条元数据记录；思考、发散、判断和二次创作应当进入 `200 Neoplasma`。

## 准入标准

满足任意一条即可进入：

- 未来可能被正式引用；
- 信息体量足够大，例如书、论文、长文、课程、播客；
- 预计会反复回看；
- 已经派生出多个 `200` 节点；
- 属于某个长期项目的核心资料。

随机看到的一句话、网页碎片、生活中偶然触发的念头，不需要为了合法化 `200` 而先登记到这里。

## 推荐标签

```txt
#outer
#capture
#paper
#book
#article
#podcast
#video
```

## 与 200 的关系

`100` 不再是 `200` 的父节点，而是来源血缘。  
一篇 `200` 可以链接到一个或多个 `100`，也可以没有显式外部来源。

之后 article view 可以自动生成 backlinks。
