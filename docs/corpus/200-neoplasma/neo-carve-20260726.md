## 一条只有七个字的 capture

今天的 corpus 新增了
[《250725 capture》](./neo-250725-cap.md)：
「论文 Result 部分的结构设计思考。」

它很短，却与 dashboard 里的当前任务精确重合：
论文需要从若干原子化分析走向「完整的论文叙事」，
teleconnection / PCA 方向似乎已经出现可讲之处，
接下来要决定哪些结果构成主干、以什么次序出现，
以及哪一项分析真正支持新意。

Results 的结构问题常被误当成排版问题：
先放时序图还是空间图，PCA 在前还是相关分析在前，
补充分析应进正文还是附录。
这些问题当然要回答，但更早的一层是：

> 读者需要依次接受哪些可检验主张，
> 才能有资格接受论文的中心结论？

分析产生的时间顺序很少能直接回答它。
研究过程允许试错、回返与支线；
论文却要把最终留下的证据组织成一条可复核路径。
若只是按「我先做了 A，后来又做了 B」排列，
Results 会变成分析日志。
若只挑最顺滑、最显著的图组成故事，
它又可能在获得戏剧性时失去证据边界。

所以这次 Carve 关心的不是怎样把结果写得更像故事，
而是怎样让故事的连贯性接受证据完整性的约束。

## 搜索路径：从 figure-first 追到选择性叙事

第一轮以 `scientific Results structure`、
`figures-first manuscript`、`logical flow scientific paper`
和 `results narrative` 为种子。

它带回一个相当一致的写作建议。
Mensh 与 Kording 的
[《Ten simple rules for structuring papers》](https://doi.org/10.1371/journal.pcbi.1005619)
把 Results 的任务写成：
用一系列彼此衔接、由图表支持的陈述，
说明中心贡献为何成立；
在提纲阶段，可以先把论证逻辑改写成陈述式小标题或图题。
PLOS 的
[首篇科学论文写作指南](https://scicomm.plos.org/2018/03/07/a-brief-guide-to-writing-your-first-scientific-manuscript)
也建议先把图表排成能够推进论述的序列，
再以这条序列作为 Results 的骨架。

第一轮留下了一个缺口：
**如果先决定中心信息与图序列，怎样防止论文只保留最配合故事的证据？**
结构越流畅，遗漏反例、敏感性与不稳定区间时反而越不刺眼。

第二轮于是转向 `selective reporting`、
`specification curve`、`raw data visibility`
和 `reporting transparency`。

这一轮改变了问题。
Weissgerber 等人的
[数据呈现研究](https://doi.org/10.1371/journal.pbio.1002128)
指出，不同的连续数据分布可能得到相同的柱形图或折线摘要；
只展示汇总形状，会遮住样本分布与异常结构。
Simonsohn、Simmons 与 Nelson 提出的
[specification curve analysis](https://pubmed.ncbi.nlm.nih.gov/32719546/)
则要求识别理论上合理、统计有效且不重复的分析设定，
展示各设定的结果，并对整组设定进行推断，
从而让分析选择对结论的影响显形。
Nature Portfolio 的
[报告标准](https://www.nature.com/commshealth/editorial-policies/reporting-standards)
进一步把可解释、可验证与可扩展所需的最小数据、
分析设计和可用性声明放进发表条件。

两轮搜索最终带回六个概念：
**central contribution（中心贡献）**、
**claim–evidence unit（主张—证据单元）**、
**figure spine（图表脊柱）**、
**argument dependency graph（论证依赖图）**、
**evidence visibility（证据可见性）**，
以及 **robustness envelope（稳健性包络）**。

它们共同给出一个更严格的方向：
Results 可以有清晰主线，
但每个转折都要暴露自己依赖了什么、
在哪些合理分析下仍成立，以及在哪里停止成立。

## Results 的最小单位应是一项主张，而非一张图

「Figure 3 显示……」很容易成为 Results 段落的起点。
但一张图可能同时承担描述、比较、验证和机制解释，
也可能画得很复杂却没有新增任何主张。
用图号作为结构单位，常会把可视化制作顺序
误认成论证顺序。

更稳固的单位是 **claim–evidence unit**。
每个单元至少包含五个位置：

1. **问题**：这一小节正在消除哪个不确定性；
2. **主张**：读者看完后应能复述的陈述；
3. **证据**：哪张图、哪组估计或哪项检验直接支持它；
4. **边界**：主张在哪些时期、区域、变量或设定下减弱；
5. **桥**：这个结果为什么使下一项主张成为必要。

例如，标题「PCA 结果」只标出了方法。
它没有告诉读者这一步在论证中做什么。
更可审查的内部工作标题可以是：

- 「主要空间模态在目标时期内可辨认」；
- 「第一模态的时间变化与候选遥相关信号同步」；
- 「这种联系集中于部分区域或季节」；
- 「改变时间窗与预处理后，联系的方向保持但强度变化」。

这些句子目前只是结构占位，
不能代替 froQ 的实际结果。
它们的价值在于迫使每一节领取有限断言权。
若一张图无法支持标题中的动词，
问题便会在正式写作前暴露：
可能要换图、缩小主张，或承认缺少一段证据。

## 图表脊柱负责带路，证据可见性负责防止带偏

**figure spine** 是把主图按阅读顺序排成一列，
只看图题与图注也能看到论证怎样推进。
PLOS 的
[科学图表规则](https://doi.org/10.1371/journal.pcbi.1003833)
强调，设计图表前要先识别它所承担的信息，
同时保持图与数据之间的紧密联系。

因此，每张主图可以先写一张「图卡」：

```text
Figure N
回答的问题：
允许的主张：
不能推出的结论：
关键对照或不确定性：
依赖的前置结果：
读完后进入的下一问：
```

其中「不能推出的结论」尤其重要。
相关图不能自动领取因果解释，
一个代表性时段不能领取长期稳定性，
一个主导模态也不能自动领取唯一机制。
图卡把这些限制留在制作现场，
避免图变漂亮以后，主张在措辞中悄悄膨胀。

图表脊柱解决的是导航；
**evidence visibility** 解决的是读者能否独立检查。
一张主图可以突出中心模式，
但不应把所有会改变判断的分布、样本量、异常值、
空间异质性与估计不确定性全部藏进 prose。

这不意味着正文必须塞满所有诊断图。
更合适的分层是：

- 主文展示改变中心判断的证据；
- 补充材料保留复核主张所需的完整诊断；
- 数据与代码支持重新生成结果；
- 正文明确指出边界证据在哪里，而非让附录成为遗忘区。

主文与补充材料的分界因此不由「图是否好看」决定。
判断标准更接近：
删除它以后，读者是否仍能正确校准对中心主张的信心。
若答案是否定的，它就属于主论证，
即使结果不整齐。

## 连贯性与完整性之间，需要一份稳健性包络

一篇论文当然需要选择。
把所有尝试过的分析按时间顺序倾倒出来，
不会自动产生透明度，反而可能淹没真正的判断。
风险来自另一种选择：
只展示最支持中心结论的一条预处理、一个时间窗、
一个空间尺度或一种模型设定。

**robustness envelope** 试图把两端接起来。
它不要求穷举一切可能分析，
而要先声明一组与研究问题相容、
统计上合理且彼此有实质差异的设定，
然后说明中心主张在这组设定中的生存范围。

对 teleconnection / PCA 一类结果，
可考虑的包络维度可能包括：

- 时间窗、季节定义与去趋势方式；
- 标准化、缺测处理与空间加权；
- 保留模态数、符号约定与旋转选择；
- 相关或回归中的滞后、协变量与多重比较处理；
- 空间留出、时间留出或事件留出；
- 个别区域、年份或极端事件对整体估计的影响。

这里不预设每一维都必须进入当前论文。
应由实际主张和方法决定合理集合。
关键是把「为什么只报告这个设定」
从隐含选择改成可说明的研究决定。

稳健性包络也不只产生「稳健 / 不稳健」二值答案。
更有信息的结果可能是：

- 方向稳定，效应大小对时间窗敏感；
- 全国平均成立，区域符号并不一致；
- 主要模式可重复，遥相关解释只在部分季节成立；
- 结论依赖某一预处理，因此应降级为条件性发现；
- 一个极端年份驱动大部分关系，值得改写研究问题。

这些边界未必削弱论文。
它们有时正是新意所在：
现象何时成立、在哪里改变、被什么尺度掩盖，
比一条无条件的平均关系更接近环境系统的真实结构。

## 一个模型：Results 论证图

把六个概念收束起来，
我会把 Results 设计为一张
**results argument graph（Results 论证图）**。

图中的节点不是分析文件，也不是图号，
而是一项项有限主张；
边表示读者接受后一项主张前，
必须先知道或相信什么。

一条常见但可调整的主链可能是：

```text
数据与尺度可解释
  → 目标现象确实存在
  → 现象具有可重复的时空结构
  → 候选驱动与该结构存在条件性联系
  → 异质性或机制分析排除部分替代解释
  → 稳健性与边界检验限定结论
  → 中心贡献成立于明确范围
```

这不是通用模板。
描述性研究、机制研究、预测研究与方法论文
会拥有不同的依赖图。
真正通用的是三个约束。

### 约束一：先按依赖排序，再按戏剧性排序

如果读者必须先相信模态稳定，
才能理解其与遥相关指数的联系，
那么稳定性证据应先出现。
一张视觉上更抓人的相关地图，
不能跳过前提抢到开头。

### 约束二：每个节点只领取证据覆盖到的主张

节点标题、图题、正文动词与不确定性表达应同级。
证据只支持 association，正文便不写成 drive；
证据只覆盖某个时段，标题便不扩张为长期规律。

### 约束三：反例不是旁注，而是图的边界节点

改变中心结论强度的异质性、敏感性和失败情形，
应在主图上拥有位置。
它们可以使节点降级、分叉或终止，
而不只是被塞进最后一段 limitations。

这样形成的 Results 仍然有叙事。
它的张力来自不确定性怎样逐步缩小，
而非来自把所有不顺滑证据剪掉。

## 带回当前论文：先做一页论证清单

对当前「论文重新凝练 + 最终实验」阶段，
最小动作不是立即重写 Results prose。
可以先建立一页论证清单，
每行对应一个候选节点：

| ID | 候选主张                         | 直接证据               | 关键边界           | 依赖     | 图表        | 状态 |
| -- | -------------------------------- | ---------------------- | ------------------ | -------- | ----------- | ---- |
| R1 | 研究对象呈现待解释的时空变化     | 描述性结果             | 数据覆盖与尺度     | 数据检查 | Fig. ?      | 待核 |
| R2 | PCA / EOF 提取出可解释的主要结构 | 模态、方差与稳定性诊断 | 模态可分性         | R1       | Fig. ?      | 待核 |
| R3 | 候选遥相关信号与主要结构存在联系 | 相关 / 回归及不确定性  | 时段、滞后、协变量 | R2       | Fig. ?      | 待核 |
| R4 | 联系具有区域、季节或事件异质性   | 分层与对照             | 样本量、多重比较   | R3       | Fig. ?      | 待核 |
| R5 | 中心判断在合理设定下保留         | 敏感性 / 留出分析      | 失效条件           | R1–R4    | Fig. / SI ? | 待核 |

表中的文字全部是待核占位，
没有替 froQ 宣布任何研究结果。
实际使用时，应删除无法由现有分析直接支持的行，
并把导师所说的「平淡」拆成可检验问题：

- 中心贡献是否只有现象描述，缺少区分性发现；
- 新意是否存在，却被埋在错误的结果顺序里；
- 某项分析很复杂，但没有改变任何主张；
- 最关键的异质性或边界仍未被做成主结果；
- 叙事依赖一项尚未通过稳健性检验的联系。

这张清单还有一个直接用途：
它可以决定「最终实验」究竟补什么。
只补能够修复关键断边、排除强替代解释，
或确定中心主张边界的分析。
若新增实验只让某个已有节点多一张相似图，
却不改变依赖图，边际价值可能很低。

一个可执行的 90 分钟切片可以是：

1. 用一句话写中心贡献，暂时允许粗糙；
2. 从现有图表中提取 5–7 个候选主张；
3. 为每项主张填写直接证据与不能推出的结论；
4. 画出依赖箭头，删除不通向中心贡献的孤立节点；
5. 标出一条最危险的断边，作为下一项分析候选；
6. 让每张主图拥有陈述式工作标题，再检查标题是否越证据。

完成标准很窄：
得到一条可从 R1 走到中心结论的主链，
并明确一项最值得补的证据。
此时先不润色段落，也不重画全部图。
结构探针若失败，修改一页清单的成本
远低于重写完整 Results 后才发现论证断裂。

## 对这条方法的克制判断

**事实**：论文写作指南普遍建议以中心贡献组织 Results，
把结果改写为由图表支持、逻辑衔接的陈述序列；
图表设计研究强调先明确图的消息并保持与数据的联系；
透明报告与 specification curve 一类方法则要求
分析选择、底层数据与合理设定对结论的影响可见。

**推断**：这些原则可以组合成 Results 论证图：
用主张节点获得清晰主线，
用依赖边检查推理跳跃，
用证据可见性与稳健性包络约束叙事选择。
这是一种写作—分析接口，
因为结构上的断边会反向指出尚缺的实验或敏感性检验。

**剩余不确定性**：我尚未读取 froQ 当前论文、图表与分析代码，
因此无法判断实际中心贡献、PCA 与 teleconnection 的证据强度，
也不能确定 R1–R5 是否适合真实研究。
不同目标期刊对 Results / Discussion 合并方式、篇幅、
主图数量与补充材料也有不同要求。

最小验证是把现有图题和小节标题放进一页论证清单。
若仅看这些标题就能复述中心主张、证据次序与失效边界，
模型有用；
若它迫使复杂研究削成一条过度线性的故事，
则应保留分叉图，允许两条相互独立的证据链
共同支持一个较克制的结论。

## 小结：让结果的顺序承担证明责任

central contribution 决定论文希望留下的中心判断；
claim–evidence unit 把 Results 拆成有限、可核查的主张；
figure spine 让读者看到论证怎样前进；
argument dependency graph 检查每一步是否跳过前提；
evidence visibility 保留独立复核的入口；
robustness envelope 则说明主张在合理选择中能活到哪里。

一份好的 Results 不需要复刻发现过程的所有弯路，
也不应把弯路中发现的反例全部抹平。
它要做的是重新排列证据，
让每个结论都能沿依赖边返回数据，
让每个边界都能在信心膨胀前被看见。

论文叙事因此不是给结果加一层戏剧包装。
它更像为读者修一条可通行、可回头检查的路：
前方每出现一项新主张，
身后都留着足以说明「为什么能走到这里」的路标。

当 Results 的顺序开始承担证明责任，
「有讲头」才不只意味着故事听起来顺。
它意味着中心判断拥有一张可以被质疑、被复核，
也能在证据不足处诚实停下的结构图。
