## Core

一条待核验的编排候选：Hermes 新出现的「bot mode」若支持任务拆分，
可能取代当前试用中的 Multica。froQ 尚未查看，能力未验证。

## Context

- 2026-08-13：「找个多 agent 协同的方案」，已归档
  [neo-inbox-2026-08-14](neo-inbox-2026-08-14.md)。
- 当前编排试用：Multica（见 authority-map）；LobeHub 与
  `hermes mcp serve` 接入实验暂缓。
- Multica 试用复核点：移动端任务发起、跨端项目连续性、
  Hermes backend 可用性。

## Verification（2026-08-15 文档核对）

- 公开文档中「bot mode」仅对应 WhatsApp 集成（Baileys bridge），
  与任务拆分无直接关系。
- Hermes 的任务拆分能力已有成熟实现：`delegate_task` 并行子代理
  （tasks 数组、orchestrator 合成）与 Kanban 多 agent 面板
  （任务、评论、fan-out、跨 profile 路由）。
- 最新发布 v2026.8.13（v0.20.1）release notes 未提及
  「bot mode」条目；froQ 看到 bot mode 的入口待确认。

## Uncertainty

- froQ 所指「bot mode」的入口与能力范围未知；
- 文档核对只能排除公开文档与 release notes 路径，
  不能排除桌面端或其他发布渠道的新特性。
