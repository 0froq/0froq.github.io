## Core

**同一段原始表达可以被多路径消费，而不是被过早绑定到单一输出形式。** 语音、笔记、随手想法都是原料，播客、博客、任务、知识节点、日记是不同的消费方式。

## 消费路径

同一段语音可以同时进入：

1. **播客**：语音 → 提取主题 → 追问补充 → 重组结构 → 写成讲稿 → 重新录制
2. **博客 / 文章**：适合承载长逻辑链和反复打磨
3. **Corpus 六层**：根据内容性质拆入不同生态位
4. **Dashboard / board**：生成任务候选（新增 note、status 变化、backlog 新增等）

关键约束是，board 不能随原始输入自动写入——语音只能生成候选，结构性变更需要确认。

## 与 000 Autopsia 的关系

这个模型带有一个系统级含义：Corpus 的六层不只是“文件分类”，而是一条消费管线。每一层按自己生态位的规则消费原料，不要求原料在进入时就已经完成分类。
