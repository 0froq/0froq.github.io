## Core

**提问能唤起记忆，尤其是那些自主叙述时不会主动想起、但被问到就会重新浮现的信息。** 主持人不只是听众，而是记忆和叙事的牵引器。

## Context

这个判断来自语音备忘录实践中的发现。

自主叙述有两种常见模式：

1. **时间线叙述**：先讲发生了什么，再补每个节点的思考。优点是连贯，缺点是不断挖坑，很多当时的想法可能被漏掉。
2. **联想式叙述**：讲到一个事件时立刻展开当时想到的东西。优点是保真，缺点是结构容易散。

两种模式都有一个共同盲区：叙述者只能讲自己主动想起的东西。而很多时候，真正重要的信息不在主动记忆的表面，它在深处，需要一个提问把它钩出来。

对于单人工作流来说，最佳替代方案可能是访谈式输入：由 agent 提问，自己回答。

## Tension

访谈式叙述的代价是失去独白的流动感。主持人的提问会打断叙述的沉浸，但换来信息密度和记忆深度。

这可能是一个可接受的权衡：如果语音备忘录的首要目标是“尽可能多地捕捉真实信息”，而不是“产生优美叙事”，那么被提问打断是值得的。
