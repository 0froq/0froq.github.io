## 一把新键盘，同时启动了两场实验

Tracker 昨日捕捉到一份 Corne V4 迁移体验，
Cast 随后留下
[《Corne V4 迁移经验：把人体工学收益放进适应成本里看》](../../rune-activity/2026-07-22-corne-v4-migration.md)。
那则 note 已经提出一个稳妥的两周可回滚试用：
观察连续编辑后的腕部不适、常用符号与终端快捷键误触率，
以及日常输入速度是否回到可接受水平。

这条建议值得继续往下挖，因为三个指标其实来自两套不同机制。

分体、外展、帐篷角与键盘高度改变的是**身体暴露**：
腕部尺偏、前臂旋前、肩部外展、腕伸展和接触压力。
列错位、拇指键、层与快捷键重排改变的是**技能映射**：
旧动作能否迁移、新动作能否保持、真实工作能否调用它。

前者可能在摆好键盘时立即变化；
后者通常要经过数日或数周练习。
若把它们压成一句「适应得好不好」，会出现两种误判：

- 第一天打字变慢，于是认定人体工学设计没有收益；
- 第一天手腕觉得新鲜舒服，于是认定长期疼痛风险已经下降。

两者都越过了证据。
输入速度只测到了当下表现，主观舒适也只测到了短时体验；
它们还没有回答技能是否真正学会，
更没有证明某种姿势改变会转化为长期症状改善。

因此，这次 Carve 想把 Corne 试用改写成一项
**双时间线迁移实验**：

> 身体适配与技能学习可以同时发生，
> 但应分别记录、分别判断，最后才讨论净收益。

## 搜索路径：先问「更自然」，再问「真的学会了吗」

第一轮搜索从 `split keyboard wrist posture`、
`ulnar deviation typing`、`alternative keyboard learning curve`
和 `ergonomic keyboard symptoms evidence` 出发。

它很快带回一个重要的不对称：
关于分体键盘减少某些危险姿势的证据相对直接，
关于它在真实工作中减少肌肉骨骼症状的结论却更复杂。
例如 Marklin 与 Simoneau 的
[腕部和前臂姿势研究](https://stacks.cdc.gov/view/cdc/191592/cdc_191592_DS1.pdf)
报告，分体键盘把双腕平均尺偏从约 12°
降到接近中立位的 5°以内。
OSHA 的
[键盘工作站指南](https://www.osha.gov/etools/computer-workstations/components/keyboards)
也把键盘选择放在整个工作站中理解：
键盘过高或过低、鼠标距离、手臂伸取与肩部抬高
会共同改变姿势暴露。

第一轮暴露的缺口是：
「姿势变了」怎样与「使用者适应了」区分？
Corne 又不只是把标准 QWERTY 从中间切开，
它还可能同时改变列布局、拇指职责、键数和层。
于是第二轮把关键词转向
`typing distributed practice`、`motor learning retention transfer`、
`learning performance distinction` 与
`contextual interference`。

这轮带回六个有用概念：
**postural exposure（姿势暴露）**、
**symptom outcome（症状结局）**、
**geometry–mapping decoupling（几何—映射解耦）**、
**acquisition–learning distinction（习得表现—学习区分）**、
**distributed practice（分布式练习）**，
以及 **retention / transfer（保持与迁移）**。

它们共同改变了试用问题：
不再只问「多久恢复原速度」，
而要问身体是否进入更低暴露的姿势、
新技能能否在隔日保持，
以及它能否迁移到代码、终端、中文输入与压力场景。

## 姿势改善是一条近端证据，症状改善是一条较远证据

分体键盘最容易观察的作用，是改变手臂到键帽之间的几何关系。
当左右模块可以按肩宽分开并旋转时，
手腕不必为了适应一条笔直键盘边缘持续向小指侧弯曲；
加入适量 tenting，又可能减少前臂完全旋平的需求。

这类指标属于 **postural exposure**。
它们接近设备设计本身，能用照片、视频、角度或体感快速发现。
但「姿势更接近中立」仍不能单独推出
「长期疼痛一定减少」。
疼痛与疲劳还受工作时长、休息、既有损伤、按键力量、
桌椅高度、鼠标位置、压力和总负荷影响。

一篇关于替代键盘的
[证据综述](https://link.springer.com/chapter/10.1007/978-3-642-39182-8_22)
把这个差异说得很清楚：
文献较强地支持替代键盘减少潜在危险姿势，
对工作场景中肌肉骨骼症状是否改善则更为不确定。

这不是说主观不适没有价值。
相反，疼痛、麻木、疲劳和局部压力是试用中必须记录的安全信号。
只是它们承担的判断不同：

- 姿势观察回答「设备有没有改变目标暴露」；
- 短时舒适回答「当前配置是否立即制造明显问题」；
- 多日症状趋势回答「在真实负荷下是否出现可重复变化」；
- 医疗结论需要更完整的个体评估，不能由一次设备试用代替。

因此，试用不宜追求一个合并分数。
速度提高不能抵消持续疼痛，
短期舒服也不能抹去越来越高的误触与肌肉代偿。
身体账本应保留否决权：
若出现新的持续疼痛、麻木或明显恶化，
应先停止或调整，而非把它解释为学习曲线必经阶段。

## 几何变化与映射变化，最好分阶段引入

固定角度 split QWERTY、可分离 QWERTY、列错位 Corne
与重新设计的 layer keymap，常被统称为「换人体工学键盘」。
但它们改变的变量数量完全不同。

Anderson 等人的
[替代键盘学习曲线研究](https://pubmed.ncbi.nlm.nih.gov/19634307/)
比较了固定分体、凹面分体、Dvorak 与 chord keyboard。
研究中的固定分体键盘较快接近传统 QWERTY 表现；
更大幅度改变形状或映射的设计需要更多恢复时间。
CDC 收录的另一项
[分体与垂直倾斜键盘研究](https://stacks.cdc.gov/view/cdc/217922)
则指出，参与者在替代键盘上练习十小时以上后，
传统与替代条件之间没有明显表现差异。

这些研究不能直接预测某个人学习 Corne 需要几天。
设备、任务、样本和熟练水平都不同。
它们支持的较窄判断是：
**改动的类型会改变学习成本，练习会改变性能比较。**
未经熟悉就比较速度，容易把陌生度当成设备能力。

由此可以提出 **geometry–mapping decoupling**：
在可行时，不要第一天同时最大化所有变化。

一个更可解释的顺序是：

1. 先保留熟悉的字母布局，调整左右距离、旋转、tenting 与高度；
2. 确认身体姿势与鼠标位置没有制造新的负担；
3. 再引入拇指键与少量高频层；
4. 最后处理符号、导航、窗口管理和低频组合键。

这样做的代价是迁移期更长，也可能需要临时 keymap。
收益是归因更清楚：
腕部不适来自 tenting 过高、掌托接触、键盘过高，
还是来自为了找符号而持续紧张，较容易被分开。

这不是要求永远一次只改一个键。
某些布局必须成组改变才有意义，
例如拇指键与 layer-tap 的职责会互相约束。
原则仍然是昨日「兼容性前沿」中的那条：
分组或拆分取决于耦合边，
而非机械追求单变量。

## 当天变快，只能证明当天表现变好了

运动学习研究区分 **performance during acquisition**
与较持久的 **learning**。
练习中的即时速度会同时受到熟悉、提示、疲劳、热身、
注意力和反馈频率影响；
真正的学习通常要靠隔一段时间后的 retention test，
以及在新任务中的 transfer test 来观察。

关于这一边界的
[学习—表现综述](https://doi.org/10.1016/j.bbr.2011.11.028)
专门提醒：练习结束时的表现差异，
不应直接等同于延迟保持中的学习差异。
对键盘迁移，这会产生三个不同问题：

- **acquisition**：今天练习到最后十分钟，速度与误触怎样；
- **retention**：隔夜后不先热身，能否恢复昨天的动作；
- **transfer**：能否在真实代码、终端、中文输入、快捷键与压力下使用。

纯打字测试最容易高估迁移。
它通常集中测字母与空格，
却很少覆盖 froQ 的真实负载：
中英文切换、括号与运算符、数字、导航、复制粘贴、
窗口管理、Neovim 模态命令和 shell 控制键。

如果在打字网站恢复到原速度，
但每次写代码仍要停下来寻找 `{}`、`|`、`~`、`Esc`
或方向层，那么学会的是测试材料，
还没有迁移到工作系统。

因此，速度指标最好至少拆成三类：

1. 普通文本，用来观察基本字母动作；
2. 代码与终端片段，用来观察符号和控制键；
3. 一段真实工作，用来观察注意力是否仍被键盘本身占据。

第三类不一定需要自动记录。
一句「今天是否因为找键而中断思路」
有时比再跑一次 WPM 更接近迁移完成度。

## 练习剂量要看可吸收性，不看一次忍了多久

Baddeley 与 Longman 的经典
[打字训练研究](https://gwern.net/doc/psychology/spaced-repetition/1978-baddeley.pdf)
比较不同长度与频率的训练安排。
每天一次一小时的组在单位训练时间上最有效，
每天两次、每次两小时的密集组最差；
作者据此建议，在现实允许时把键盘训练分布到时间中，
而非集中堆叠。

这给「两周适应」增加了一条必要修正：
日历经过十四天，不等于获得十四天有效学习。
一次练到手部疲劳、错误增多、注意力涣散，
可能同时污染身体账本和技能账本：
不适来自设备，还是来自过量练习，开始无法区分。

**distributed practice** 更适合 Corne 迁移：
短而规律的练习、足够休息、隔日冷启动观察，
再逐渐增加真实工作负荷。
它不承诺一定更快到达最高速度，
但有助于减少疲劳混杂，并让 retention 变得可见。

第二轮搜索还遇到
[contextual interference 的系统综述与元分析](https://pmc.ncbi.nlm.nih.gov/articles/PMC11237090/)：
变化较多、随机交错的练习有时会让当下表现更差，
却可能改善延迟保持；
但这一优势在应用场景里可能很小，不能机械套用。

带回键盘迁移，一个克制的实践是：

- 初期用稳定小任务建立基本映射；
- 稍后混入文本、代码、终端与导航，检验 transfer；
- 不用故意把练习变得混乱来追求所谓「高质量困难」；
- 若随机切换只制造疼痛、挫败或大量无信息错误，就降低难度。

训练的目标不是证明能吃苦，
而是让新映射在不同任务里都能被低成本调用。

## 一个模型：双账本迁移

把这些概念收束起来，
我会把人体工学设备试用写成一份
**dual-ledger migration（双账本迁移）**。

### 身体账本：设备改变了什么暴露

记录对象可以很少，但要可比较：

- 左右模块距离、旋转、tenting、高度与掌托方式；
- 连续工作 30、60、90 分钟后的腕、前臂、肩颈不适；
- 是否出现麻木、刺痛、新的局部压力或代偿姿势；
- 鼠标是否因此更远，肩部是否为了键盘高度被迫抬起；
- 调整后变化能否在下一次相似负荷中复现。

这本账的完成标准不是「忍到不痛」。
它要找出一组不会持续制造新问题、
并能合理改善目标姿势的配置区间。

### 技能账本：映射是否保持并迁移

记录对象应覆盖真实工作：

- 冷启动普通文本速度与误触；
- 高频符号、快捷键和 layer 的查找停顿；
- 隔夜后的 retention；
- 文本、代码、终端、中文输入之间的 transfer；
- 是否仍需把注意力从内容抽回键位。

这本账不要求立即达到旧键盘峰值。
更重要的是观察趋势：
错误是否集中在少数可调整键位，
隔夜回退是否缩小，
真实任务是否逐渐不再被设备打断。

### 净收益账：两个系统是否终于能同时成立

两周结束时，不把所有指标简单平均，
而使用带门槛的判断：

1. **安全门**：没有持续恶化或新的神经症状；
2. **姿势门**：目标暴露确实改善，且未把负担转移到肩、鼠标或掌托；
3. **学习门**：retention 与真实任务 transfer 呈改善趋势；
4. **工作门**：关键编辑与终端任务回到可接受水平；
5. **可逆门**：旧键盘与旧 keymap 仍可恢复，试用没有绑架正式工作。

其中任何一门失败，都比综合平均分更有解释力。
身体门失败，优先调整几何或停止；
技能门失败，检查练习剂量和 keymap；
工作门失败，允许新旧设备分工更久；
可逆门失败，则说明试用设计本身投入过重。

## 对 Corne 的一个最小可归还实验

沿用
[《枝条需要一条返回路径》](../000-autopsia/aut-carve-20260721.md)
的语言，这次迁移可以成为一条可归还枝条：

- **来源锚点**：Tracker 与 Cast 发现的 Corne V4 使用经验；
- **依赖边**：它 `informs` 是否值得采用，不阻塞当前工作；
- **生长预算**：两周，保留旧键盘，不在试用期重做全部个人快捷键；
- **停止条件**：新症状持续、正式任务明显受阻且无改善，或配置调整无法解释问题；
- **再入线索**：用身体账、技能账和五道门决定保留、调整、延长或退出。

还可以把两周切成三个可逆阶段：

### 第 1–3 天：只找可居住的几何

保持尽可能熟悉的字母布局，
以短时文本和轻工作为主。
调整距离、旋转、tenting、高度与鼠标位置；
每天只改一个主要几何变量，避免追着瞬时体感来回摆动。

### 第 4–9 天：建立最小工作映射

固定几何，集中处理最常用的拇指键、导航、删除、
中英文切换与终端控制键。
练习分布到多个短时段，记录隔夜冷启动，
不以一次最长训练作为进步证据。

### 第 10–14 天：把键盘放回真实生活

混入代码、终端、长文本与日常通信。
观察 attention cost：
是否仍频繁从任务内容退回键位搜索；
同时检查工作负荷增加后身体指标是否仍成立。

两周以后，可能得到的好结论不只「买」或「不买」。
也可能是：

- 几何有效，但当前 keymap 过度激进；
- 打字已迁移，终端控制键仍需重构；
- 工作日用 Corne，某类高压任务暂时保留旧键盘；
- 设备没有问题，但桌高与鼠标位置抵消了收益；
- 个体没有观察到净收益，停止试用比继续适应更合理。

这些结论都比「我还没习惯」更可行动。

## 小结：让身体与技能在不同速度上说真话

split geometry 改变腕与前臂的姿势暴露，
但近端姿势证据不能自动升级为长期症状结论；
alternative keyboard learning curve 说明，
设备改动类型与练习量会改变性能比较；
geometry–mapping decoupling 让人体工学配置与键位学习
尽可能获得独立归因；
learning–performance distinction 又把当天顺手
与隔日保持、真实迁移分开；
distributed practice 最后提醒，
适应不是把困难集中忍完，而是让动作有机会在休息后留下来。

人体工学设备因此不该只接受一场速度考试。
它同时接受两场审查：
身体是否减少了不必要的暴露，
技能是否在真实工作里重新变得透明。

理想状态也并非「再也感觉不到键盘」。
更准确的完成信号是：
身体不再为旧几何持续让步，
注意力也不再为新映射持续缴税。

两条时间线最终可以会合，
但不应在第一天被迫给出同一个答案。
让身体与技能分别说真话，
才有可能判断一把键盘带来的究竟是新鲜、忍耐，
还是可持续的净收益。
