## 搜索路径：从漂亮模态走向断言预算

我以 `climate teleconnection PCA pitfalls`、
`EOF physical interpretation rotation`、
`field significance multiple testing climate` 和
`causal attribution teleconnection nonstationarity` 为种子向外搜索。

第一轮原本只想整理 PCA / EOF 的常见注意事项，
却被 orthogonality、domain dependence、North's rule 与 mode mixing
带回一个更底层的问题：数学上最善于解释方差的方向，
为何会被读成自然界最重要的过程？

第二轮继续追问遥相关显著性和因果路径，
又遇到 field significance、false discovery rate、
causal pathway、mediator / confounder 与 regime-dependent causality。
这些概念共同提示：一张地图不只需要显著，
还需要说明自己站在证据梯的哪一级。

### EOF 的正交性是算法合同，不是自然法则

NCAR 的
[EOF / REOF 指南](https://climatedataguide.ucar.edu/climate-tools/empirical-orthogonal-function-eof-analysis-and-rotated-eof-analysis)
说得很直接：EOF 并不基于物理原理，
而是把一个场分解为数学上正交的模态；
这些模态有时可以被解释为大气或海洋结构，但这种解释不是算法保证。

正交约束尤其容易制造误会。
真实气候过程可以共享空间、相互耦合，也可以同时受第三个过程驱动，
它们没有义务彼此垂直。
PCA 却必须把总方差分配到相互正交的轴上。
所以一个物理过程可能被拆进多个 PC，
多个过程也可能被挤进同一个 PC。

EOF 又具有 **domain dependence（区域依赖）**。
改变研究区域、变量尺度、标准化方式、季节窗口或时间段，
协方差结构会改变，模态也可能旋转。
如果一个「全球湖泊共同模态」只在某个经纬度范围、
某种面积权重或某个时期成立，它仍可能是有用摘要，
却不能被写成独立于分析设计的自然实体。

这给 PCA 一个更准确的角色：它是**坐标提案**。
它提出「沿这些方向看，数据最容易被压缩」；
后续分析再判断这些方向是否稳定、可命名，
以及是否与已知物理过程拥有超出视觉相似的关系。

### North's rule：相邻特征值靠得太近时，模态会互相渗漏

North 等人在
[EOF 抽样误差研究](https://journals.ametsoc.org/view/journals/mwre/110/7/1520-0493_1982_110_0699_seiteo_2_0_co_2.pdf)
中指出，当相邻特征值之差与抽样误差处于相近量级时，
对应 EOF 的地理形状可能在不同样本间大幅变化。
常用的 North's rule of thumb 正是用来判断相邻模态能否被可靠区分。

这意味着 PC1、PC2 的序号没有天然本体论。
如果两者解释方差接近，bootstrap、年份删减或数据产品替换后，
它们可能发生 **mode mixing**、**mode swapping**，甚至符号翻转。
符号翻转本身通常不重要，因为特征向量正负任意；
模态交换则会直接影响「第二模态对应 Victoria Mode」之类的命名。

因此，稳定对象有时不是某一个 PC，
而是由几个近简并模态共同张成的子空间。
如果分析只追踪 PC2 的相关图，可能把坐标轴的抽样旋转
误当作气候关系发生了变化。
更稳的做法是同时报告特征值间隔、重采样后的模态相似度，
并在必要时比较子空间，而不执着于单个编号。

### Field significance：空间连续的显著区域也可能由偶然长出来

遥相关分析经常在许多湖泊、格点、时间滞后和气候指数之间
计算相关或回归。
Katz 与 Brown 早已把这种问题称为
[teleconnection research 中的 multiplicity](https://doi.org/10.1002/joc.3370110504)：
测试数量增加以后，即使每个检验都使用 0.05 阈值，
至少出现一些假阳性的概率也会迅速上升；
气候序列的自相关又会减少有效样本量，使普通显著性进一步偏乐观。

更隐蔽的是，空间自相关会让假阳性看起来并不随机。
邻近格点共享噪声结构，偶然信号也可能形成一片连续色块，
而连续形状恰恰最容易被解释成物理区域。
2026 年关于气候空间多重检验的
[开放研究](https://link.springer.com/article/10.1007/s13253-026-00738-5)
明确提醒：未校正的显著点可以形成貌似可解释的连片结构。

**Field significance（场显著性）**问的是整张场是否包含
超出随机预期的信号；
**false discovery rate（FDR）**则控制所有被称为发现的格点中，
预期有多大比例是假的。
两者都比逐点 `p < 0.05` 更接近空间问题，
但也各有代价：全场检验可能错过局部强信号，
普通 FDR 在空间相关条件下可能过于保守或依赖特定条件。

这里的原则不应退化成「必须选某一种校正」。
更重要的是先承认，地图包含一族同时发生的判断，
不能把每个像素当作互不相关的单次实验。
如果分析还遍历了多个滞后、多个 PC、多个指数，
这些选择也属于 multiplicity，不能只校正最终展示的那一张图。

### 稳健性不是多画几张相似图，而是主动寻找断裂面

一张相关图通过 FDR，仍只说明关联不像随机噪声。
下一步需要问，这个形状是否依赖某个窄而隐蔽的分析决定。

可以把稳健性拆成几种不同断裂面：

- **时间断裂**：前半段、后半段、leave-period-out 或 blocked bootstrap
  是否保留同一结构？
- **产品断裂**：不同 LSWT / SST 产品、不同再分析是否给出相近方向？
- **预处理断裂**：去趋势、去全球均值、季节定义、标准化与面积权重改变后怎样？
- **模态断裂**：PCA 区域、保留模态数、协方差矩阵与相关矩阵改变后怎样？
- **尺度断裂**：湖泊级、区域聚合与大陆级结果是否讲述同一关系？

这不是要求每个结果在所有处理下纹丝不动。
有些机制本来就只在特定季节、区域或背景态成立。
关键在于，断裂位置本身必须进入解释：
它究竟暴露统计不稳定，还是揭示了一个有物理意义的条件。

由此可以区分 **robustness** 与 **invariance**。
前者要求结论不被任意分析选择轻易推翻；
后者要求某种关系跨环境、时期或产品保持相对稳定。
一个 teleconnection 可以统计上稳健，却随气候 regime 改变；
也可以全时期相关很弱，却在两个相反背景态中分别稳定。

### Regime-dependent causality：全时期平均可能把两种真实关系抹平

气候遥相关并不天然平稳。
[Regime-oriented causal analysis](https://esd.copernicus.org/articles/14/309/2023/)
显示，Atlantic–Pacific 相互作用会随 PDV 与 AMV 的位相组合改变，
不同背景态拥有不同的因果 fingerprint。
另有 Regime-PCMCI 工作尝试识别因果方向、滞后、效应强度和符号
如何随潜在 regime 改变。

这与 2013/14 regime shift 的研究问题直接相遇。
如果假设北太平洋状态转换改变了全球湖泊的远程响应，
把 1981–2020 全部混在一条相关系数里，
可能同时犯两种错误：

1. 两个时期方向相反，平均以后看起来没有关系；
2. 两个时期各自没有稳定关系，恰好因共同趋势拼出全时期相关。

因此，移动窗口或分 regime 分析不只是为了展示时间变化，
它在检验「遥相关是否拥有持续的关系结构」。
但窗口也会再次制造多重选择与低统计功效，
尤其 post-hiatus 段只有十余年时，不能把一条波动曲线写成确定的机制演化。

比较诚实的表达可以是：
全时期关联提供候选路径，分段结果检验其条件性；
若样本不足，则把 regime dependence 作为不确定性与未来检验，
而非用更多窗口制造更强确信。

### Causal pathway：远程共变需要一条中间道路

Kretschmer 等人的
[《Quantifying causal pathways of teleconnections》](https://doi.org/10.1175/BAMS-D-20-0117.1)
提出，研究遥相关的因果路径需要把领域知识显式放进统计框架。
这件事不能由「相关在前、影响在后」自动完成。

以北太平洋 SST 与湖泊温度为例，二者可能同时响应全球强迫，
也可能经由大气环流、云量、辐射、降水、积雪、冰封期和局地气温等
一条或多条路径连接。
如果只放入远端 SST 与 LSWT，得到的是总共变，
无法区分直接、间接和共同驱动。

因果图语言在这里带回三个很有用的角色：

- **confounder（混杂因素）**：同时影响远端指数与湖泊响应，
  若不处理会制造或夸大关联；
- **mediator（中介变量）**：承载遥相关的物理路径，
  例如环流异常经局地气温影响 LSWT；
- **collider（碰撞点）**：同时被两个变量影响，
  对它条件化反而可能打开一条虚假路径。

这解释了为什么「加入更多控制变量」并不总是更严谨。
控制局地气温，可能是在排除共同天气噪声；
如果局地气温正是遥相关作用于湖泊的主要中介，
控制它又会把真正想估计的路径一起切断。
必须先声明目标是总效应、直接效应，还是某条中介路径，
再决定条件化什么。

因果发现方法如 PCMCI 可以帮助区分直接与间接的时滞依赖，
但它们也依赖平稳性、充分观测、函数形式与无隐藏混杂等假设。
它们不会把观察数据自动变成实验。
更成熟的组合是：领域知识先画出候选 DAG，
统计方法删除部分不相容的边，
模式试验、再分析一致性或大集合模拟再检验路径是否可重现。

## 一架证据梯：每一级只允许一组动词

把这些概念放在一起，我会把 teleconnection / PCA 分析写成
一架 **claim ladder（断言梯）**。
每一级都很有价值，但只能领取与证据相称的动词。

### 第一级：压缩

证据：PCA / EOF 找到解释较多方差的轴与对应时间系数。

允许说：`概括`、`分解`、`解释方差`、`呈现主要共变方向`。

暂不允许说：`代表某物理模态`、`由某过程驱动`。

这一层的核心诊断是面积权重、标准化、domain dependence、
North's rule、bootstrap 稳定性与近简并子空间。

### 第二级：关联

证据：PC、气候指数、SST 场或湖泊响应之间存在相关、回归、合成差异。

允许说：`相关`、`协变`、`与……一致`、`提供候选遥相关`。

暂不允许说：`影响`、`导致`、`传递`。

这一层需要处理有效样本量、自相关、multiple testing、
field significance / FDR，并防止只展示最大、最好看的结果。

### 第三级：稳健结构

证据：关联跨时间块、数据产品、预处理和合理参数选择仍然存在，
或其变化能被明确的 regime 条件解释。

允许说：`稳健关联`、`可重复空间结构`、`具有状态依赖性`。

仍需谨慎说：`teleconnection mechanism`。

这一层最重要的动作不是堆更多图，
而是预先定义哪些断裂会让主张降级。

### 第四级：方向与路径

证据：合理 lead–lag、条件独立关系、候选 DAG、
已知环流路径或中介变量共同支持方向性。

允许说：`与某传播路径相容`、`提示远端影响可能经……传递`、
`支持候选因果路径`。

仍不宜单凭观察资料说：`证明机制`。

这一层要特别说明混杂、中介、碰撞点、隐藏变量与方法假设。

### 第五级：机制归因

证据：统计路径与物理理论一致，能在独立资料、模式试验、
大集合或干预式敏感性实验中重现，并排除主要替代解释。

这时才较有资格说：`驱动`、`介导`、`贡献于`，
而且通常仍应给出作用范围、条件和不确定性。

这架梯的目的不是让论文永远停在「相关不等于因果」。
那句警告太宽，容易把所有发现一起压平。
梯子反而允许分析积极前进：每补上一类证据，
就获得更强一点、但边界清楚的语言。

## 对当前 teleconnection / PCA 工作的一个轻量协议

如果当前结果确实「有讲头」，最有价值的下一步未必是立即把它写成机制，
而是先为它建立一份断言预算。
一页检查表就够：

1. **对象是什么**：PCA 分解的是湖泊时间序列、加速度、
   空间场，还是某组 teleconnection 指标？
2. **坐标是否稳定**：PC 编号、符号、空间负载和解释方差
   在重采样与替代预处理下是否稳定？
3. **搜索空间有多大**：试过多少 PC、指数、滞后、窗口与区域，
   最终显著性是否覆盖了完整选择过程？
4. **关系在哪一级**：当前只有压缩、关联，还是已经跨产品、跨时期稳定？
5. **替代解释是什么**：共同趋势、全球均值、局地 SAT、湖泊属性、
   空间聚集或数据产品结构能否生成同样图形？
6. **路径经过哪里**：若称为遥相关，最短的候选物理链是什么，
   哪些变量是混杂，哪些是中介？
7. **什么结果会使主张降级**：换时期即消失、仅一个产品成立、
   相邻 PC 交换、FDR 后归零，分别意味着什么？

这份协议也可以直接帮助 outline 分层：
先写发现了怎样的低维结构，再写它与哪些远端场关联，
随后报告稳健性与 regime dependence，
最后才讨论与哪些物理路径一致、哪些仍需要验证。

如此即使最终没有走到机制归因，结果也不会失去价值。
一个稳定、条件明确的全球湖泊响应模态，
本身就可能是很强的描述性发现；
一个只在 2013/14 之后出现的候选远程联系，
也可以成为清楚的 future direction，
而不必为了叙事吸引力提前领取因果语言。

## 小结：图形给机制一个入口，不替机制走完道路

EOF / PCA 的 orthogonality 与 domain dependence 说明，
模态首先是由数据域和目标函数共同产生的坐标；
North's rule、mode mixing 与 mode swapping 提醒，
单个 PC 的编号和形状可能受有限样本影响；
field significance、FDR 与 multiplicity 说明，
空间连续的显著区域也可能由多重检验和自相关长出来；
regime-dependent causality 又表明，遥相关关系可能随背景态改变，
不能默认整段时间共享同一张因果图；
causal pathway、confounder、mediator 与 collider 最后要求我们说明，
远端共变究竟可能沿哪条物理道路传递。

这些概念并不削弱 teleconnection / PCA 的潜力。
它们只是把潜力从「这张图很像一个故事」
变成「这张图已经取得哪一种作证资格」。

一篇有吸引力的论文，不需要让第一张漂亮地图承担全部机制。
它可以让地图成为入口，让稳健性决定路是否存在，
让时滞与条件关系标出方向，
再让物理知识与独立证据判断这条路通向哪里。

遥相关地图最初是一张候选机制图。
它最珍贵的地方，不是远处的色块已经替我们解释了世界，
而是那些色块让下一次验证终于知道该往哪里走。

湖泊遥相关格局与主成分分析的旧问题；
它没有复述具体分析结果，而是追问统计模态怎样取得物理解释的作证资格。

探索式搜索以 climate teleconnection PCA pitfalls、
EOF physical interpretation / rotation、
field significance / multiple testing 与
causal attribution / nonstationarity 为种子，
进一步带回 orthogonality、domain dependence、North's rule、
mode mixing / swapping、field significance、FDR、
regime-dependent causality、causal pathway、confounder、mediator
与 collider 等概念。
本文核心产出是 **claim ladder（断言梯）**：
压缩、关联、稳健结构、方向与路径、机制归因五个层级
各自拥有不同的证据责任和可使用动词，
避免 PCA / EOF 的统计坐标因形状清楚而被直接写成物理实体，
也避免用一句「相关不等于因果」抹平描述性发现的真实价值。

这一判断适用于气候遥相关、空间统计、PCA / EOF、
生态网络与其他高维科学分析，核心产出是可迁移的研究解释原则，
而非 corpus 自身的系统级决策或元认知方法调整，
因此写入 `200-neoplasma`，而非 `000-autopsia`。
