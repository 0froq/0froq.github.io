<ruby><rb>Autopsia</rb><rt>dissection</rt></ruby> 是 Corpus 的自我解剖层。

这里不承担普通捕捉，不作为 inbox，也不存放日常碎片。
它只记录系统和主体对自身的观察：认知结构如何变化，知识系统如何失衡，某个长期阶段如何结束，某套方法论为什么需要被修正。

## 放在这里的东西

- Corpus 架构调整与复盘
- 阶段性自我审问
- 知识工作流的诊断
- 认知模式、能量节律、创作机制的观察
- AI patrol / growth 输出被确认、反驳或改写后的系统级结论

## 不放在这里的东西

- 随手捕捉的资料线索 → `100 Ingesta + #capture`
- 突然冒出的想法 → `200 Neoplasma + #capture`
- 当天发生的事和实践流水 → `300 Putredo`
- 审美刺激 → `400 Delirium`
- 私人存在片段 → `500 Vigil`
