> Source: [About Yak Shaving](https://antfu.me/posts/about-yak-shaving)

Yak Shaving refers to a series of actions when you're working on one task
and then you find another task that's not finished, you tackle that one first,
and while you're working on that one, you find another task to do… and so forth,
so that you stray from the work that should have been done,
and end up not getting nothing finished.

Shave the Good Yak
