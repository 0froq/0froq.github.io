<ruby><rb>Putredo</rb><rt>decay</rt></ruby> 是现实摩擦层。

这里不只是普通日志。它记录一个想法、项目、任务、身体状态或关系现场进入现实后发生的变形、失败、阻滞和残余。

如果说 `200 Neoplasma` 是新生组织，`300 Putredo` 就是这些组织接触空气、水分、泥土和压力之后开始腐烂、发酵、供养下一轮生长的地方。

## 放在这里的东西

- 项目推进记录
- 实验和分析过程
- 工具链实践
- 工作流试运行
- 执行失败与阻滞
- 身体、环境、他人对计划的反作用
- 日常流水中可能产生残渣的部分

## 记录规则

一天最多一个正式 `put-YYYYMMDD.md`。  
多个主题追加到同一个文件的不同章节，不新建第二个 put 文件。

如果当天只有零散捕捉，可以先写在 `## Capture` 下，并加 `#capture`。之后再在 `## Residue` 中判断它应该流向哪里。

## Residue 协议

每篇 `300` 结束时可以留下一个很短的残渣区：

```md
## Residue

- can be distilled into 200:
- should update board:
- should enter 000 autopsia:
- discardable noise:
```

这样日志不会停在“发生过”，而会继续供养概念层、任务系统和元认知层。
