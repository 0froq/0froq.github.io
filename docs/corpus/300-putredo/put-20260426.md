## 分析框架

### 旧的

之前太依赖于 hiatus 这个概念，
很先入为主地认为一定要在所有的湖泊上找到 hiatus 的区间，
且还想尽量与 1998-2012 的 global warming hiatus 区间重叠。
但实际上，hiatus 这个概念本身就存在争议
（见 [前几天的 put](put-20260422.md)），
在全球尺度上都很取决与定义、区间等等因素，
就更不用说在单个湖泊上了。

而且之前在做单湖分析的时候也发现了，
hiatus 的区间在不同的湖泊上差异很大，
甚至有些湖泊根本就没有所谓 hiatus，显著性也普遍不好。

这几天又做了一次确认，用 10-18 年窗口来找 1986-2020 年间趋势最不显著的区间
（hiatus 的定义之一），
发现落在 1998-2012 年附近的数量不多，
坐实了「湖泊对 global warming hiatus 的响应不一致」这个结论。

### 新的

所以，用了新的分析框架：**三段式结构识别**。
即，在一定程度上认同 global warming hiatus 的存在，
但认为湖泊对其的响应具有高度的异质性，
即湖泊会有不同的响应模式，甚至有些湖泊根本就没有明显的响应，
故在 1998±4 年和 2012±4 年之间的区间内，
寻找两个转折点，来将整个时间序列分成三段，
分别对应 global warming hiatus 前、中、后三个阶段，
并分析这三个阶段的趋势、显著性、变化率等等指标，
来总结不同湖泊的响应模式。
三段的识别是基于统计方法的，
目前用的方式是在 1998±4 年和 2012±4 年之间的区间内，
找断点组合，使三段的回归拟合显著优于单段的拟合。
不过这里的标准可以再商榷，当前是让 LLM 做的，我没有太检查技术细节。

所以我们得到了各个湖泊的「三段式结构」，现在计算各段的趋势，
通过趋势的不同组合来判定其「**响应原型**」。
下面给的是判断逻辑链（可能一些命名后续会改，但整体逻辑应该不大变）：

- ==若=={.before:bg-emerald-500}：三段拟合没有显著优于单段拟合 / 两个断点前后的分段趋势差异不显著
  => ==No significant change==
- ==否则，若=={.before:bg-emerald-500}：三段趋势单调
  （前段趋势 > 中段趋势 > 后段趋势 / 前段趋势 < 中段趋势 < 后段趋势）
  => ==Shift==
  - ==若=={.before:bg-emerald-500}：三段趋势均为正/负
    => ==sustained warming/cooling==
  - ==否则=={.before:bg-emerald-500}：三段趋势存在正负交替
    => ==shift==
    - ==若=={.before:bg-emerald-500}：
      中段趋势的绝对值小于前后两段趋势的绝对值，
      且前段趋势大于/小于后段趋势
      => ==high/low platform==
    - ==否则=={.before:bg-emerald-500}：
      前/后段趋势的绝对值小于中段趋势的绝对值，
      且前段趋势大于/小于后段趋势
      => ==early/late cooling/waring shift==
- ==否则=={.before:bg-emerald-500}：三段趋势不单调
  => ==Buffer==
  - ==若=={.before:bg-emerald-500}：中段趋势的绝对值小于前后两段趋势的绝对值，
    且前后段趋势均为正/负
    => ==warming/cooling hiatus==
  - ==否则，若=={.before:bg-emerald-500}：中段趋势为正/负
    => ==warming/cooling acceleration==

我知道分类很乱，名字也有点问题，不过大概的逻辑应该没什么问题。
