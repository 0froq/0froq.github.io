# Signal Decomposition as Cognitive Model

时间序列分析方法与人类认知之间存在着一种结构性的对称——这不是隐喻层面的凑巧，而是两者在处理复杂系统信息时遵循着相同的数学直觉：**任何复杂信号都可以（且应该）被分解为不同时间尺度的组分**。

## 三种分解，三种认知模式

### STL → 分层归因

STL（Seasonal-Trend decomposition using LOESS）将信号拆为三项：趋势、季节项、残差。这是一种**加性归因**的认知策略——面对复杂局面时，先剥离长期趋势（事物在往哪里走），再识别周期性模式（哪些是重复出现的节律），余下的是真正不可归约的「事件」。

这与双相特质人群的自我认知策略高度同构：区分「基线状态」（trend）与「能量节律」（seasonal），从而避免将周期性的高涨或低落误判为根本性的自我改变。STL 不预设 seasonality 的周期长度——这种灵活性恰好对应了个体节律的非均匀性。

### EEMD → 多尺度直觉

Ensemble Empirical Mode Decomposition 将信号分解为一组 IMF（Intrinsic Mode Functions），每个 IMF 捕捉一个特征时间尺度上的振荡。不需要预设基函数，分解完全由数据驱动。

这与「直觉」的运作方式惊人地相似：有经验的研究者看一张时间序列图，不需要跑任何统计检验就能感知到「这里有十年尺度的趋势」「这里有年际振荡」「这里有个异常点」。这种感知不是模糊的整体印象，而是视觉皮层在大脑中自动完成了多尺度分解。EEMD 本质上是对这种生物信息处理的形式化。

### 小波变换 → 上下文敏感的认知

小波的独特之处在于**时间-频率局部化**：它不只在频率域分解信号，还保留每个频率组分在时间上的位置。某个 5 年周期的振荡在前半段很强、后半段消失——小波能告诉你这件事，而傅里叶不能。

这对应着一种**情境化的认知风格**：同一类行为在不同时间段的含义不同，同一套方法论在不同研究阶段的适用性不同。小波思维拒绝「一概而论」，要求在时间轴上动态地理解事物的权重。

## 突变检测与人生叙事

Pettitt 检验、Bayesian changepoint 等方法识别序列中的结构突变——均值的永久位移、方差的模式变化。这与人生中的「转折点」叙事结构完全同构：不是连续的渐变，而是可定位的相变。

一个有自我叙事能力的人，本质上是在对自己的时间序列做 changepoint detection——识别哪些节点是「之前」与「之后」的分界。这种识别不是任意的，它需要信号（行为、情绪、产出）发生了统计上可检测的结构性变化。

## 为什么这种类比有价值

不是因为「数学很美所以生活也应该是数学的」，而是因为**时间序列分解方法的底层逻辑——在不同尺度上分离因果——恰好是人类理解自身最有效的心智策略**。

froQ 的「模拟器思维」之所以高效，正是因为它默认了这种多尺度分解：把现实问题抽象为变量（信号组分），在脑内推演互动（系统模拟），再落地。这不是一种思维风格的选择，而是对复杂系统信息结构的最佳适应。

当数学方法和心智模型指向同一个方向时，那个方向通常是对的。
