# 学术工具链 2026：写作系统与科学可视化

> 2026-05-31 巡检整理。蛙蛙作为环境科学研究者 + 全栈开发者，同时处在学术写作与 Web 开发两个世界的交汇点。这篇覆盖学术写作工具的三极格局（Typst/LaTeX/Quarto）与科学数据可视化工具的 Python/JS 双生态。

---

## 一、学术写作系统：Typst / LaTeX / Quarto 三极格局

2026 年的学术写作工具不再是 LaTeX 一家独大。Typst 从「有趣的替代品」成长为有实际战斗力的选项，Quarto 则作为科学出版的中立桥梁连接两端。

### 1.1 Typst：LaTeX 四十年来最严肃的挑战者

**版本演进**

- **v0.13.0**（2025-02-19）：段落/行内内容明确区分（为无障碍化铺路）、outline 全面重构（更好的默认外观、悬挂缩进、全宽链接）、`curve()` 取代 `path()`、图像支持原始像素光栅格式、函数接受 raw bytes、WASM 插件自动多线程、HTML 导出实验性支持（`--features html`）
- **v0.13.1**（2025-03-07）：Bug 修复
- **v0.14.0**（2025-10-24）：**可访问性 PDF**（默认 tagged PDF、PDF/UA-1 合规）、支持全部 PDF/A 标准（从 1b 到 4e）、PDF 作为原生图像格式（hayro 库，纯 Rust，零系统依赖）、字符级对齐（`par.justification-limits`）、HTML 导出大幅扩展（Model 类别全覆盖、typed HTML API）、多表头表格、`title` 元素、`frac.style`（skewed/inline 分数）、大量元素变为 locatable（可被 `query` 发现）、增量编译算法优化、CLI 增强（`typst info`、`typst completions`、`--deps`）
- **v0.14.1**（2025-12-03）、**v0.14.2**（2025-12-12）：WASM 运行时安全修复

**核心优势**

| 维度      | 数据                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------- |
| 编译速度  | 全文干净构建 ~15s（vs LaTeX 90s+）；增量变更 <1s（vs LaTeX 需重新编译）                                 |
| 语法      | Markdown-like + Rust-inspired，`<=`→≤、`1/x` 自动分数、括号自动缩放                                     |
| 错误信息  | 清晰可操作（vs LaTeX 的级联错误难以排查）                                                               |
| 脚本能力  | 内置编程语言（循环、条件、函数），vs LaTeX 的宏系统                                                     |
| 可访问性  | v0.14 起默认 tagged PDF，支持 PDF/UA-1，EAA（欧盟 2025.06.28 起）/ADA Title II（2026.04.24 起）法规合规 |
| HTML 导出 | 实验性但快速发展中，Model 类别已全覆盖                                                                  |

**现实障碍**

- **期刊 .tex 要求**：NeurIPS、ICML、ACL 等顶会仍要求 .tex 源文件（但越来越多接受 PDF 投稿）
- **生态规模**：100+ 包 vs LaTeX 的 CTAN 6000+
- **AI 工具**：LaTeX 有 Overleaf AI（TeXGPT、Error Assist、Writefull），Typst 的 AI 工具链在早期阶段

### 1.2 Quarto：科学出版的瑞士军刀

Quarto 定位在 Pandoc 之上，提供从单一源文件到多种输出格式（LaTeX/Typst/HTML/PDF/docx）的管道。2026 年的最大变化是 Typst 支持大幅追赶 LaTeX。

- **v1.7**（2025-04）：深色模式改进（brand.yml 双主题、`renderings` 计算输出主题映射、`respect-user-color-scheme`）、Typst 更新至 0.13.0、Pandoc 3.6.3、Julia 引擎改进（juliaup 集成、R/Python 代码格、缓存）
- **v1.9**（2026-03-24）：
  - **Typst book 项目**：`type: book` + `format: typst` 现在工作，使用 `orange-book` 扩展，支持 Parts/Chapters/Appendices/交叉引用/目录
  - **Article Layout**：边注（Marginalia 包）、全宽图表、旁注引用
  - **typst-gather**：自动打包 Typst 包依赖，离线渲染无需网络
  - **PDF 无障碍标准**：PDF/A 和 PDF/UA 合规（LaTeX + Typst 均支持）
  - Chrome Headless Shell 取代 Puppeteer Chromium（更小、arm64 兼容）
  - 依赖更新：Typst 0.14.2、Pandoc 3.8.3
- **v1.10.x**（2026 后续）：持续迭代中

### 1.3 LaTeX：稳固的基础设施

LaTeX 的优势不在技术先进性，而在**制度性嵌入**——期刊模板、同行协作习惯、AI 工具生态。

**Overleaf AI 能力矩阵**（2025-2026）

Overleaf 与 Writefull（均为 Digital Science 旗下）深度整合：

| 功能                                   | 描述                                                                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **AI Assistant**（Overleaf Labs beta） | 上下文感知的 LaTeX 写作助手，LaTeX 代码生成与排错、引用审查器（基于 Dimensions 的 1.6 亿篇文献库，检测缺引并推荐参考文献，一键插入） |
| **TeXGPT**                             | 生成 LaTeX 代码、创建大纲/示例/骨架文档、内容解释、格式修正                                                                          |
| **Error Assist**                       | 解释 LaTeX 错误并建议修复（局限：不感知自定义命令）                                                                                  |
| **Writefull 语言建议**                 | 语法/流畅度编辑，针对学术写作训练，支持多语言                                                                                        |
| **公式/表格生成器**                    | 从图片或自然语言 prompt 生成 LaTeX 代码                                                                                              |
| **改写工具**                           | 改写/精简/科学化/拆分/合并句子、生成标题/摘要、同义词建议                                                                            |

**LaTeX Kernel 2026-06**

- `\DocumentMetadata` 新键：`language`/`other-languages`（BCP-47 标准字符串）
- `\NewDocumentCommand` 空键值列表处理改进
- Block template 自定义细化，更好模拟 `enumitem`
- 标准数学字体 Unicode 映射改进（改善 PDF 中的复制粘贴体验）
- `amsmath` 间距 bug 修复
- 文档重命名：`latex-cmds` → `cmdguide`

### 1.4 实战策略：什么场景用什么

```
┌─────────────────────────────────────────────────────┐
│  新项目、个人笔记、学位论文（PDF 投稿 OK）           │
│  → Typst（速度快、语法简洁、modern feel）            │
│                                                     │
│  最终期刊投稿（要求 .tex 源文件）                    │
│  → LaTeX（无可替代的制度性要求）                     │
│                                                     │
│  多格式输出（HTML+PDF+docx）、Reproducible Research  │
│  → Quarto（单一源文件，多目标输出）                  │
│                                                     │
│  实用混合：Typst 草稿 → Pandoc/社区工具 → LaTeX 投稿 │
│  （享受 Typst 开发体验，满足投稿要求）               │
└─────────────────────────────────────────────────────┘
```

**对蛙蛙的关联**：蛙蛙既写学术论文（环境科学/GIS，投稿期刊用 LaTeX），也做技术文档和博客（可用 Typst/Quarto）。Quarto + Typst 的 book 项目能力对学位论文写作尤其有用。Overleaf AI 的引用审查器（基于 Dimensions）可能直接帮助论文文献管理。

## 二、科学数据可视化工具 2026

蛙蛙的数据流：ERA5/湖泊数据 → Python（xarray/pandas）→ 可视化 → 论文图表 / Web 展示。以下覆盖 Python 与 JS 双生态的最新状态。

### 2.1 Python 生态

#### Matplotlib 3.10

- **Petroff10 色循环**：算法保障的无障碍性（色盲建模 + 机器学习美学评分），可能成为新默认
- **暗模式发散色图**：`berlin`、`managua`、`vanimo`（Crameri Scientific colour maps 8.0.1）
- **3D 改进**：鼠标旋转（Shoemake ARCBALL）、`fill_between` 3D、动态裁剪到视图范围
- **free-threaded CPython 3.13 初步支持**
- **其他**：`EngFormatter` 自动偏移、`ax.table()` 接受 Pandas DataFrame、`FillBetweenPolyCollection`、`InsetIndicator` artist
- 3.10.9（2026-04-23）为当前最新补丁版本

#### HoloViz 生态

HoloViz 是蛙蛙这种「大数据 + 地理空间」场景最有价值的 Python 可视化套件。核心组件：

- **hvPlot 0.12.x**：Pandas/Xarray/GeoPandas 的 `.plot()` 超集，同一 API 背后是 Bokeh/Matplotlib/Plotly/Datashader/GeoViews/Cartopy。NumFocus 小额资助已用于文档大修，目标 2026 年初发布 1.0。规划中：Donut/Pie 图类型、Param 2.0 reactive expressions 重构 `.interactive()`、Narwhals 后端（Polars 原生支持）
- **Datashader 0.19.0**（2026-03-20）：**band-wise 2D quadmesh**（多波段栅格直接渲染）、Pandas 3.0 / Python 3.14 / cuDF 26.02 兼容、quadmesh 性能大幅提升（numba 加速、矩阵乘法优化 colorize、`float32` 转换）。移除了自 0.17 起已损坏的 CLI
- **Panel**：交互式 Dashboard 框架，Scipy 2026 有专门教程。AI 使用指导正在开发中（NumFocus 资助项目）

#### 其他值得关注

- **Plotly/Dash**：Web 端交互可视化的另一条路，适合快速搭建仪表盘
- **xarray + hvPlot**：蛙蛙的气候数据处理管道的天然搭配——xarray 处理 NetCDF/GRIB，hvPlot 一行 `.plot()` 出交互图

### 2.2 JavaScript/Web 生态

蛙蛙作为 Vue.js 开发者，前端可视化工具栈同样重要。

#### D3.js

仍然是自定义数据可视化的金标准。2026 年状态：

- D3 由 Observable 维护，官网重新设计
- 模块化架构不变（`d3-scale`、`d3-array` 等不操作 DOM 的模块可在 React/Svelte 中直接使用）
- 与 Observable 平台深度整合（notebook 中默认可用）

#### Observable Plot 0.6.17（2025-02）

D3 团队开发的高级 API，定位类似 Vega-Lite 但语法更直觉：

- **GeoJSON clip**：可将可视化裁剪到任意多边形边界（如国界线裁剪气象数据，避免阿拉斯加-加州错误插值）
- **Waffle mark 改进**：tip 锚点优化
- **difference mark**：时间序列指标对比
- **shift transform**：时间偏移指标
- **categorical color** 默认 `observable10` 色方案

#### Observable Notebooks 2.0

- 缓存/快照系统大幅改进（Canvas 分析加载更快、SQL 错误信息更好、查询可取消）
- AI Assist 扩展支持 Observable Plot、D3 等
- 嵌入式分析、定时通知、Cloud 发布

## 三、几个值得注意的趋势

1. **可访问性从可选变为必须**：EAA（2025.06.28 生效）和 ADA Title II（2026.04.24 最后期限）意味着 Typst 0.14 的 PDF/UA-1 支持和 Matplotlib 的 Petroff10 都不只是「nice to have」，而是合规要求。学术论文也可能在投稿系统中逐步被要求符合无障碍标准。

2. **Typst 与 LaTeX 的边界在模糊**：Quarto 1.9 让 Typst 的 book 和 article layout 追上了 LaTeX。下一步可能是更多期刊提供官方 Typst 模板。Springer LNCS、IEEE 已有社区移植版，NeurIPS 和 ICLR 也在推进。

3. **Python 可视化的「大数据」路径成熟**：Datashader 0.19 + hvPlot 的交互管道，让蛙蛙的湖泊大数据集（百万级）可以在普通笔记本上流畅可视化，无需预聚合。

4. **AI 正在改变学术写作与可视化工具**：Overleaf AI 集成深度惊人（引用审查器直接查 Dimensions 1.6 亿篇文献）；HoloViz 正在探索 AI 辅助数据探索；Observable 的 AI Assist 支持 Plot 和 D3。写代码越来越不是瓶颈，判断和审美越来越是。
