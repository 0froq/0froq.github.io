# 客制化硬件：机械键盘生态全景

> 2026-05-31 20:00 巡检自主学习
>
> froQ 兴趣列表中「客制化硬件」在 55 轮巡检中始终未被触及。本轮填补。机械键盘是客制化硬件中与开发者工作流最直接交叠的领域，也是「软件工具链定制」哲学向物理层延伸的自然节点。

---

## 一、为什么键盘

**键盘是开发者与世界之间唯一的物理接口。** 代码从大脑到屏幕，中间只经过键盘。一个软件工程师每天在键盘上敲击数万次，手指移动的总距离以公里计。但大多数人从未想过这个接口可以被重新设计。

在 froQ 的世界里，Neovim 的键位映射、Zellij 的模态快捷键、Ghostty 的 Key Tables —— 这些都是在软件层面对输入的重新编排。**客制化键盘将这个编排权的边界从软件向下延伸到了物理层。** 你不只决定按下什么键触发什么行为，你还决定键在哪里、用什么力度触发、发出什么声音、手指在键与键之间移动多远的距离。

这是一个关于控制权的叙事：从「接受厂商定义的工具」到「定义自己的工具」。

## 二、键盘解剖学

一把客制化键盘可以拆解为五个独立可替换的层级：

### 2.1 套件（Kit）

外壳 + PCB + 定位板的组合。决定了键盘的物理形态、配列和结构刚性。材质从塑料到铝合金到铜，装配方式从 tray-mount 到 gasket-mount 到 top-mount，每种方案影响声音共振和打字手感。

### 2.2 轴体（Switches）

键盘的灵魂。三大类型：

- **线性轴（Linear）**：平滑无段落感，直上直下。Cherry MX Red / Gateron Yellow / Kailh Cream。游戏玩家和追求纯粹流畅感的用户首选。
- **段落轴（Tactile）**：触发行程中有可感知的「凸点」。Cherry MX Brown / Holy Panda / Zealios。为打字和编程提供物理反馈，手指可以在触底前知道按键已触发。
- **有声段落轴（Clicky）**：段落感 + 咔嗒声。Cherry MX Blue / Kailh Box Jade。打字机式的听觉满足感，但需要独立空间。

2026 年的新趋势：磁轴（Hall Effect）支持可调节触发点、快速触发（Rapid Trigger），在电竞领域快速渗透。光轴（Optical）以光信号替代金属触点，理论上无限寿命。

关键参数：触发力度（35g~80g+）、触发行程（1.0~2.2mm）、总行程（3.0~4.0mm）、润滑状态（出厂润滑/手润）。

### 2.3 键帽（Keycaps）

键盘的面孔。决定了视觉风格和指尖触感。

**材质**：

- ABS：色彩鲜艳、触感光滑，但长期使用会打油（GMK 的 ABS 双色注塑是顶级方案）
- PBT：更耐打油、触感更粗糙，部分人觉得白灰调不够鲜艳（ePBT、PBTfans）
- POM：自润滑、声音更沉，少数派选择

**高度与形状（Profile）**：

| Profile | 高度          | 雕刻     | 顶面     | 特点                              |
| ------- | ------------- | -------- | -------- | --------------------------------- |
| Cherry  | 低 (~9.4mm)   | 逐行雕刻 | 圆柱     | 爱好者标准，80% 市场份额          |
| OEM     | 中 (~11.9mm)  | 逐行雕刻 | 圆柱     | 预装键盘默认方案                  |
| SA      | 高 (~16.5mm)  | 逐行雕刻 | 球面     | 复古打字机美学，深沉 thock 声     |
| MT3     | 高 (~12-16mm) | 逐行雕刻 | 深球面   | Matt3o 设计，深邃指窝引导手指归位 |
| DSA     | 低 (~7.6mm)   | 统一     | 扁平球面 | 适合 ortholinear 布局             |
| XDA     | 中低 (~9.2mm) | 统一     | 扁平宽面 | 现代极简，大面积指触              |
| KAT     | 中 (~11mm)    | 逐行雕刻 | 球面     | SA 的实用替代，不那么高           |

**雕刻 vs 统一**：雕刻按键每行高度不同，引导手指；统一按键所有行等高，适合非标准配列（ortholinear、40%）。

### 2.4 固件（Firmware）

键盘的操作系统。三大阵营：

**QMK（Quantum Mechanical Keyboard）**：C 语言编写，开源社区标准。支持 3000+ 键盘。完全可编程 —— 层、组合键、宏、鼠标键、RGB 控制、自定义算法。缺点是需要编译和刷写，学习曲线陡峭。

**ZMK**：基于 Zephyr RTOS，无线优先。专为蓝牙/BLE 分体键盘设计，功耗极低。支持多设备切换、左右半自动配对。正在逐步侵蚀 QMK 在无线分体市场的份额。

**VIA / Vial**：不是独立固件，而是 QMK 兼容的图形化配置工具。VIA 让用户可以在浏览器里实时重映射键位、创建层、录制宏，不需要编译。Vial 是 VIA 的开源分支，增加了动态按键编辑、QMK 设置修改等高级功能。

决策框架：有线 → QMK；无线分体 → ZMK；不想碰命令行 → VIA/Vial。大多数人日常用 VIA，只在需要 VIA 不支持的功能时才编译 QMK。

### 2.5 线材与配件

螺旋线（coiled cable）、航空插头（aviator connector）、腕托（wrist rest）、消音棉（foam）、轴下垫（PE foam）、卫星轴（stabilizers）—— 每一个细节都是可调的变量。

## 三、配列（Form Factor）：键在变少，自由在变多

键盘尺寸按键数递减：

| 配列        | 键数 | 保留了               | 放弃了               | 适合                                 |
| ----------- | ---- | -------------------- | -------------------- | ------------------------------------ |
| 全尺寸 100% | 104  | 所有                 | 无                   | 数据录入、会计                       |
| TKL 80%     | 87   | F 键、方向键         | 数字区               | 游戏、通用办公                       |
| 75%         | ~84  | F 键（紧凑）、方向键 | 数字区、Home 簇      | **开发者**（需要 F 键做 IDE 快捷键） |
| 65%         | ~68  | 方向键               | F 键、数字区         | 平衡体积与功能                       |
| 60%         | 61   | 仅字母区             | F 键、方向键、数字区 | 极简、桌面空间最大化                 |
| 40%         | ~47  | 字母区（无数字行）   | 几乎所有             | 终极极简，重度依赖层                 |

**越小的键盘，越依赖于层（layer）机制。** 在 QMK 中，你可以定义多个虚拟层，通过按住特定键（如拇指位置的 FN）切换。40% 键盘用户可能定义了 5 个以上的层，数字、符号、导航、功能键各自一层。这和学习 Neovim 的 modal editing 是同构的思维方式 —— 放弃物理键的「可见性」，换取手指移动的最小化。

### 特殊排列

**Ortholinear（正交）**：键按网格排列，不再是传统打字机的交错行。减少手指横向移动。需要完全重新学习肌肉记忆，但理论上更高效。40% ortho（如 Planck 4×12）是客制化圈的标志性形态。

**Split（分体）**：左右手分离，可以按肩宽放置，肘部自然张开。代表产品：ErgoDox EZ、ZSA Moonlander、UHK 60、Corne（crkbd）。对长期打字者来说可能是最有实际意义的升级 —— 不是好看，是健康。

**Column-staggered（列交错）**：不是传统的行交错（stagger），而是按手指长度做列交错。Keychron Q11、Sofle、Lily58 等。结合分体和 ortholinear 哲学，是目前人体工学键盘的主流前沿。

## 四、中国的客制化键盘生态

中国是全球机械键盘产业的制造中心，也是最大的消费市场之一。2025 年全球游戏机械键盘市场约 47.2 亿美元，中国贡献了 34.6% 的出货量。中国客制化生态有几个显著特点：

**制造端**：珠三角的代工体系使得小批量定制成为可能。KBDFans、Drop、Keychron 等国际品牌的供应链根植于中国制造。国产轴体（Gateron 佳达隆、Kailh 凯华、JWK、TTC 正牌科电）在品质和创新上已经不输甚至超越 Cherry。

**社区生态**：

- **zf（装备前线 / ZFrontier）**：国内最大的键圈社区和团购平台，也是 GMK 等国际品牌的中国代理。
- **QQ 群文化**：客制化团购（Group Buy）高度依赖 QQ 群通知和 IM 口口相传，书面积累相对少。David Zhang 的《客制化机械键盘知识库》是少有的中文系统性文档。
- **墨客工作室（MoacLab）**：集设计、定制、社区于一体的中文键圈品牌，Discord + QQ 双渠道运营。
- **V2EX 机械键盘节点**：程序员群体的键盘讨论区，1147+ 主题。

**2026 趋势**：

- 磁轴（Hall Effect）爆发，75% 配列成为主流，Wooting 引领、国产厂商快速跟进。
- 全键热插拔从高端下放到百元价位，换轴不再需要焊接。
- Gasket-mount 结构成为标配，追求柔韧（flex）的打字感。
- 声音成为新维度：从「thock」（深沉）到「clack」（清脆）的声学调校，PE foam、轴下垫、case foam 等声学改装手段普及。

## 五、与 froQ 世界的连接点

### 5.1 Neovim 与键盘层：同一种思维方式

Neovim 的模态编辑（normal / insert / visual / command）本质上就是键盘层的软件实现。在 normal 模式下，`hjkl` 是方向键；在 insert 模式下，它们是字母。这和 QMK 层的逻辑完全一致：「同一个物理键在不同上下文中有不同含义」。

froQ 如果使用小配列键盘 + QMK 层，可以将 ESC 放在 Caps Lock 位置（许多 Vim 用户的刚需）、将 Ctrl 放在拇指位置（减少小指负担）、将常用组合键（如 `<leader>`+ 系列）映射到单一按键。这不是两个独立的话题，是同一个问题的两个解法。

### 5.2 客制化作为「工具链哲学」的物理延伸

froQ 的 Dotfiles、Neovim 配置、Zellij 布局 —— 这些都是对工具的深度定制。客制化键盘是这个哲学从软件走向物理的最后一步。同样的设计原则适用：

- **最小移动距离**：60%/40% 键盘减少手指移动 ≈ Vim 的 `f`/`t` 跳转减少光标移动
- **层（layer）代替扩展**：键盘层 ≈ Neovim 的 mode / Zellij 的 session 切换
- **热插拔即迭代**：换轴不需要重新焊接 ≈ Dotfiles 改一行不需要重装系统
- **开源固件**：QMK/ZMK 的 C 代码 ≈ Neovim 的 Lua 配置

### 5.3 字体设计与键帽设计：面与体的关系

froQ 对字体设计的兴趣与键帽设计共享核心关注点：**legend（印字）的字体选择、字重、对齐、间距。** GMK 键帽使用 Cherry 的原始字体模具，SA 键帽使用 Signature Plastics 的 Gorton Modified 字体。一套键帽的色彩搭配（colorway）本质上是一个 palette + typography 的设计项目。

### 5.4 命名与键盘的平行结构

和 corpus 的拉丁语命名、posts 的古汉语命名一样，键圈有自己的命名系统：Holy Panda、Zealios、Gateron Oil King、Kailh Box Jade —— 轴体的名字不只是标签，是性格声明。同样，套件的名字（Planck / Preonic / Corne / Sofle）承载着设计者的叙事野心。

### 5.5 键盘与「空间设计」

Yi-Fu Tuan 说「空间是自由，地方是安全」。在桌面上，键盘是「地方」—— 手指的锚点，身体的延伸。全尺寸键盘占用更多桌面空间但提供「每个键都在」的安全感；40% 键盘释放桌面空间但要求使用者信任层系统。这是一个空间设计决策。

## 六、入门路径（如果 froQ 未来有兴趣）

1. **不急着买**。先理解自己需要什么，而不是被 keycap 好看的照片吸引。
2. **试轴器**。花几十块买一个 9-12 键的试轴器，亲手感受线性 / 段落 / 有声段落的差异。开关数据表读不出手感。
3. **出发点选择**：
   - 想最低门槛体验可编程键盘 → Keychron Q 系列 / V 系列（VIA 原生支持）
   - 想一步到位高端 → Mode / Geonworks / TGR 级套件
   - 想极致人体工学 → ZSA Moonlander / Corne 分体
   - 想自己动手从零设计 → Ergogen v4 + KiCad + JLCPCB 打样
4. **不盲目追求「最好」**。键盘是高度个人化的设备。别人说 Holy Panda 是神轴，你不一定喜欢它的段落感。Cherry MX Brown 被圈内嘲笑为「最不 tact 的 tactile」，但对很多人来说刚刚好。
