## 1. 基础概念

### 1.1 时间序列的四个组分

任何时间序列可建模为四个组分的组合：

$$Y_t = T_t + S_t + C_t + R_t$$

- **Trend（趋势）**：长期单调变化，如湖泊表层水温的世纪尺度增暖
- **Seasonality（季节性）**：固定周期的重复模式，如水温的年循环（夏季峰值、冬季谷值）
- **Cycle（周期）**：非固定频率的波动，如 ENSO 的 2-7 年周期、PDO 的 20-30 年周期
- **Residual（残差）**：去除前三者后的随机成分，理想状况下为白噪声

**加性 vs 乘性分解**：
- 加性：$Y_t = T_t + S_t + R_t$，适用于季节性波动幅度不随水平变化的情况（如温度）
- 乘性：$Y_t = T_t \times S_t \times R_t$，适用于季节性波动幅度随水平变化的情况（如经济数据）

气候/湖泊数据几乎总是使用**加性分解**。

### 1.2 平稳性

平稳性是经典时间序列模型（ARIMA 等）的核心假设：

- **严平稳**：联合分布不随时间平移而改变
- **弱平稳（二阶平稳）**：均值恒定 + 方差恒定 + 自协方差仅依赖于时间间隔
- **趋势平稳 vs 差分平稳**：趋势平稳（trend-stationary）序列去除确定性趋势后平稳；差分平稳（difference-stationary）序列需要差分才能平稳

**检验工具**：
- ADF（Augmented Dickey-Fuller）检验：H₀ = 存在单位根（非平稳）
- KPSS 检验：H₀ = 平稳（与 ADF 互补，减少误判）
- 联合使用两者可区分趋势平稳与差分平稳

### 1.3 自相关

自相关是时间序列分析中最需要警惕的结构性问题。正自相关导致：

- 趋势估计仍然**无偏**，但**不确定性被低估**
- Mann-Kendall 检验的 Type I error 膨胀（更容易错误拒绝 H₀）
- 变点检测的假阳性激增

**处理方法**：
1. **Prewhitening（预白化）**：在趋势检验前移除 AR(1) 成分。但 TFPW（trend-free prewhitening）存在争议——先去趋势再白化可能吃掉真信号
2. **方差膨胀（Variance Inflation）**：修改检验统计量的方差以补偿自相关（Hamed & Rao 1998）
3. **时间聚合**：从日分辨率聚合到月/年以减少自相关，但会损失信息（MTUP 问题）
4. **显式建模**：在回归模型中包含 AR 项（GAMAR、GLS-AR）

Collaud Coen et al. (2020, AMT) 提出了一个三方法算法来最大化 MK 检验的 power 同时最小化假阳性。

## 2. 分解方法

### 2.1 经典分解（Classical Decomposition）

起源 1920 年代，步骤：
1. 用移动平均估计趋势-周期
2. 去趋势后按季节周期平均计算季节成分
3. 残差 = 原始值 − 趋势 − 季节

**问题**：两端丢失观测、对异常值不鲁棒、假设季节成分不变、过平滑快速变化。**不推荐**。

### 2.2 X-11 分解

Census Bureau 开发，经典分解的改进版：
- 包含自动异常值检测与修正（基于迭代加权）
- 能处理交易日效应、节假日效应
- 主要面向月度/季度经济数据

### 2.3 SEATS 分解（Seasonal Extraction in ARIMA Time Series）

基于 ARIMA 模型的信号提取。将时间序列拆分为趋势、季节、循环、不规则四种不可观测成分，用 ARIMA 建模后通过 Wiener-Kolmogorov 滤波器提取。

优势是理论基础强，但依赖正确的 ARIMA 模型识别。常用于统计局官方季节调整（如 Eurostat）。

### 2.4 STL 分解（Seasonal-Trend decomposition using LOESS）

Cleveland et al. (1990) 提出，是目前气候/地学领域最广泛使用的分解方法。

**核心机制**：
- 内层循环：LOESS 去趋势 → 按季节窗口 LOESS 平滑 → 低通滤波 → 去季节
- 外层循环：基于残差计算鲁棒权重，降低异常值影响

**关键参数**：
- `n(p)`：季节周期（月数据 = 12，日数据 = 365）
- `n(i)`：内层迭代次数（通常 1-2）
- `n(o)`：外层鲁棒迭代次数（通常 5-15）
- `seasonal_width`：季节 LOESS 平滑窗宽（奇数，控制季节成分的时间变异性）
- `trend_width`：趋势 LOESS 平滑窗宽（奇数，控制趋势的平滑度）

**优势**：
- 季节成分可随时间变化（非固定）
- 对异常值鲁棒（外层鲁棒权重）
- 可处理缺失值
- 可处理任意频率的序列（不仅是月度/季度）

**局限**：
- LOESS 在数据两端不稳定
- 计算复杂度高（大尺度全球湖泊数据 92000 个湖泊 × 40 年 = 瓶颈）
- 对趋势窗宽敏感：窗宽过大压制断点，过小引入噪声

**froQ 的 hiatus 项目中，STL 是核心预处理步骤**：对每个湖泊的 LSWT 时间序列执行 STL 分解，提取非线性趋势成分后进行 changepoint 分析。详见 `2026-05-28-stl-parameter-tuning.md`。

### 2.5 其他现代分解方法

- **STR（Seasonal-Trend decomposition using Regression）**：用正则化回归替代 LOESS，支持复杂季节性（多季节周期、非整数周期）和多个外部回归变量
- **MSTL（Multiple STL）**：处理多季节周期（如每小时数据同时有日+周+年周期）
- **Prophet（Meta 开源）**：GAM 框架 + 贝叶斯变点 + 傅里叶季节性 + 节假日效应。适合业务预测，学术场景偏弱

## 3. 趋势检测

### 3.1 Mann-Kendall 检验 + Sen's Slope

气候/水文领域的**事实标准**。

**MK 检验**：
- 非参数（不要求正态分布）
- H₀：无单调趋势
- 基于 Kendall's τ：统计量 S = ∑ sign(xⱼ − xᵢ)（所有 i<j）
- 渐进正态：Z = S/√Var(S)，其中 Var(S) 经结（ties）校正

**Sen's Slope**：
- 趋势斜率的非参数估计：median of all pairwise slopes
- 对异常值鲁棒（使用中位数而非均值）

**关键陷阱**：
- **自相关会膨胀 MK 统计量的方差**，导致过度拒绝 H₀。必须 prewhiten 或使用 modified MK（Hamed & Rao 1998）
- **季节性**：月度数据必须用 Seasonal MK（Hirsch et al. 1982），否则季节性本身会伪装成趋势
- **Power 不足**：小样本 + 小趋势 + 大方差时，MK 的 Type II error 高。Frontiers (2020) 的 Monte Carlo 模拟给出了定量关系：power ∝ slope / √(variance/n)，建议略微放宽 α 或延长序列
- **Sen's Slope 浪费数据**：自动忽略 29%-50% 的 pairwise slope 信息（不检查是否异常值即可抛弃）。回归方法（GLS）更高效

### 3.2 线性回归方法

**OLS（普通最小二乘）**：最简单，但假设独立同分布误差。在气候数据上几乎总是违反（存在自相关）。

**GLS（广义最小二乘）**：通过建模误差协方差结构来补偿自相关。趋势估计与 OLS 几乎相同（自相关不偏趋势，只偏方差），但不确定性估计更准确。

**分位数回归（Quantile Regression）**：不只估计均值趋势，可估计任意分位数（如 95th 分位数温度趋势）。对研究极端事件变化至关重要——均值不变但极端事件频率可能变化。

### 3.3 广义加性模型（GAM）

GAM 是气候趋势估计中最强大的回归框架之一：

$$g(E[Y_t]) = f_1(t) + f_2(\text{season}) + \mathbf{X}\beta$$

其中 $f_1(t)$ 是时间的平滑函数（趋势）、$f_2(\text{season})$ 是季节性的平滑函数，$\mathbf{X}$ 是外部协变量（如 PDO、ENSO 指数）。

**核心优势**：
- **趋势形状由数据决定**：不需要预设线性/二次/三次。通过 GCV（广义交叉验证）或 REML 自动选择平滑度
- **可建模季节性与趋势的交互**：季节效应可随时间变化
- **可处理非高斯响应**：Poisson（计数）、binomial（二值）、Gamma（正值偏态）
- **可包含自相关结构**：GAMM（Generalized Additive Mixed Model）或 GAMAR（GAM + AutoRegressive 项）可显式建模残差自相关
- **导数分析识别变化期**：一阶导数显著 ≠ 0 的时间段 = 正在发生统计显著变化的时期

**Palaeoecology 领域的典型应用**（Simpson 2018, Frontiers）：对不规则间隔的湖泊沉积物数据，用 GAM + CAR(1) 连续时间自相关结构估计非线性趋势，通过一阶导数的置信区间识别显著变化期。

### 3.4 方法选择决策框架

| 场景 | 推荐方法 | 原因 |
|------|---------|------|
| 简单、无自相关的线性趋势检验 | MK + Sen's Slope | 简单、非参数、鲁棒 |
| 存在自相关的趋势检验 | Modified MK（方差膨胀）或 TFPW-MK | 补偿自相关 |
| 存在季节性的月/季数据 | Seasonal MK | 季节是混淆因素 |
| 需要非线性趋势形状 | GAM / STL | 趋势形状由数据决定 |
| 需要估计趋势不确定性 | GLS-AR / GAM + 置信区间 | 提供误差带 |
| 研究极端事件趋势 | 分位数回归 | 不限于均值 |
| 多变量趋势归因 | GAM + 协变量 | 可控制外部强迫 |

## 4. 变点检测（简述）

已在 `2026-05-28-breakpoint-detection-methods.md` 深入覆盖，本轮仅简述作为全景的一部分。

**核心方法分类**：
- **单变点**：Pettitt 检验（非参数）、Buishand U/Range 检验、SNHT（标准正态同质性检验）
- **多变点**：STARS（Rodionov 2004 序贯 t 检验）、PELT/FPOP（动态规划 + 惩罚似然）、Binary Segmentation 及其改进版（Wild Binary Segmentation）
- **Bayesian**：可结合元数据先验提高检测 power

**Lund et al. (2023) 七个陷阱**（已在之前的文档中覆盖）：
1. 忽略正自相关（假阳性最大来源）
2. 对含趋势/季节性的序列使用均值 shift 方法
3. 使用 binary segmentation 的旧版而非改进版
4. 不考虑非正态性
5. 不比较 changepoint 模型 vs 趋势模型
6. 对检出变点不做 metadata 验证
7. 忽视惩罚项/阈值的敏感性

## 5. 谱分析与周期检测

### 5.1 傅里叶分析

**离散傅里叶变换（DFT）** 将时间序列从时域映射到频域。周期图（Periodogram）显示各频率的功率。

**局限**：
- 假设信号平稳（频率不随时间变化）
- 对有限样本的频率分辨率有限
- 周期图本身不连贯（需要平滑或 tapering）

**短时傅里叶变换（STFT）**：在滑动窗口上做 DFT，允许频率内容随时间变化。Lake Baikal 60 年研究中用 DSTFT 去季节性后再做趋势分析（Hampton et al. 2008）。

### 5.2 小波分析（Wavelet Analysis）

小波变换是气候科学中**周期检测的事实标准**。

**连续小波变换（CWT）**：将时间序列与缩放/平移的母小波（如 Morlet）进行卷积，产生二维时频功率谱。

**核心优势**：
- 同时在时间和频率域定位信号
- 可以检测**间歇性周期**（ENSO 在某些年代强、某些年代弱）
- 可检测频率随时间的变化
- 交叉小波（Cross-Wavelet）可分析两个序列的时频相干性

**关键陷阱**：
- 边界效应（Cone of Influence, COI）：边缘区域不可靠
- 低频伪影：CWT 在长周期处容易产生人工周期（Lau & Weng 1995; Maraun & Kurths 2004）——这是气候文献中最被滥用的方法之一
- 红噪声背景：气候序列天然具有低频高功率，必须用 AR(1) 红噪声作为显著性检验的零假设，而非白噪声

### 5.3 奇异谱分析（Singular Spectrum Analysis, SSA）

Vautard & Ghil (1989) 提出，气候科学中广泛使用。

**核心思想**：将单变量时间序列嵌入到高维相空间（类似 Taken's 嵌入定理），做 PCA 提取主要模态，再将各模态重建回时域。

**SSA 能提取三种成分**：
1. **趋势**：缓慢变化的非周期成分（对应最大特征值）
2. **振荡对**：周期性成分以**成对相等特征值**出现（两个特征向量近似正弦/余弦正交对）
3. **噪声**：剩余低方差成分

**多通道 SSA（M-SSA）**：扩展到多变量，可同时分析 SST 和 SLP 的联合振荡模式。Groth & Ghil (2015) 用 Procrustes 旋转改进了 Monte Carlo 显著性检验。

**应用案例**：Silva et al. (2024, Scientific Reports) 用 M-SSA 分析 ERA5 南大西洋 SST + SLP 数据，提取了 12.8 年周期（南大西洋偶极子）和 5.3 年周期，趋势+两振荡解释了近 40% 的方差。

## 6. 经典统计模型

### 6.1 ARIMA 家族

| 模型 | 全称 | 适用场景 |
|------|------|---------|
| AR(p) | 自回归 | 当前值 = 过去 p 个值的加权和 + 误差 |
| MA(q) | 移动平均 | 当前值 = 过去 q 个误差的加权和 |
| ARMA(p,q) | 自回归移动平均 | 平稳序列的通用模型 |
| ARIMA(p,d,q) | 差分整合 | d 阶差分后平稳的序列 |
| SARIMA | 季节性 ARIMA | 同时建模非季节和季节成分 |

**ARCH/GARCH**：方差建模（金融波动率），气候科学少用。

**Box-Jenkins 方法**：模型识别（ACF/PACF）→ 参数估计 → 诊断检验（残差白噪声）

### 6.2 指数平滑

| 方法 | 适用场景 |
|------|---------|
| Simple Exponential Smoothing | 无趋势、无季节 |
| Holt's Linear Trend | 线性趋势、无季节 |
| Holt-Winters | 线性趋势 + 季节（加性或乘性） |
| ETS（Error-Trend-Seasonal） | 状态空间框架，自动选择最优模型 |

ETS 的优势在于其状态空间表述允许计算预测区间和进行模型选择（AIC）。

### 6.3 经典方法在气候科学中的位置

经典 ARIMA/ETS 方法在气候科学中使用相对有限，原因：
1. **非平稳性**：气候序列通常含趋势和复杂季节结构，差分可能不够
2. **物理过程驱动**：物理模型（GCM、lake model）比纯统计外推更受信任
3. **归因需求**：科学问题通常是「为什么变」而非「预测明天多少度」

但在以下场景仍有价值：
- 填补缺失值（ARIMA 插值）
- 短时预测（如 ENSO 预测）
- 作为更复杂模型的 benchmark

## 7. 现代机器学习方法

### 7.1 深度学习时间序列模型

| 模型 | 机制 | 优势 |
|------|------|------|
| **LSTM** | 门控循环单元，选择性记忆/遗忘 | 长程依赖建模 |
| **GRU** | LSTM 简化版 | 参数量少、训练快 |
| **CNN-LSTM** | CNN 提取局部特征 + LSTM 时序建模 | 适合多变量 |
| **Transformer** | 自注意力机制 | 并行计算、捕获任意距离依赖 |
| **Informer/Autoformer** | 改进 Transformer（稀疏注意力/自相关） | 长序列预测效率 |

### 7.2 时间序列基础模型（Foundation Models, 2025-2026）

这一领域正在经历类似 NLP 的「预训练 + 微调」范式转移：

| 模型 | 机构 | 机制 | 特点 |
|------|------|------|------|
| **Lag-Llama** | 学术开源 | 基于 LLaMA decoder-only + lagged features | 概率预测（输出分布非点估计），开源 |
| **Chronos-2** | Amazon | T5 encoder-decoder，值缩放+量化 | 生产级成熟度，300+ forecasts/s，五尺寸 9M-710M |
| **TimesFM** | Google | Patch-based decoder-only，100B 真实时间点预训练 | 企业级，Google 内部验证 |
| **MOIRAI-2** | Salesforce | 多变量、协变量支持 | 多变量场景最强 |
| **TimeGPT-1** | Nixtla | 专有模型 | 精度/速度 benchmark 排名第一（2024比较） |

**与气候/湖泊科学的距离**：
- 基础模型预训练于经济、能源、交通等高频数据，气候/湖泊的物理过程和长时间尺度可能超出分布外
- 需要 fine-tune 才能迁移到地学场景
- 物理一致性（如能量守恒）无法保证
- 作为探索性工具有价值，但不替代物理基础的方法

### 7.3 混合方法（Hybrid Models）

当前趋势不是「ML vs 统计」而是「ML + 统计 + 物理」：

- **VMD-GRU**：变分模式分解 + GRU，先用信号分解分离多尺度成分再分别预测
- **Physics-informed Neural Networks (PINNs)**：在 loss function 中嵌入物理方程约束
- **GP Surrogate**：用高斯过程替代物理模型做不确定性量化（Zhu et al. 2025, AoAS，用于 GLM 湖泊模型预测）

## 8. 贝叶斯方法

### 8.1 贝叶斯结构时间序列（BSTS）

Scott & Varian (2014, Google) 提出的状态空间框架：

$$Y_t = \mu_t + \tau_t + \beta^T\mathbf{X}_t + \varepsilon_t$$

其中 $\mu_t$ 是局部水平（local level）、$\tau_t$ 是季节性成分、$\mathbf{X}_t$ 是回归变量。

**关键特性**：
- **Spike-and-slab 先验**：自动特征选择（哪些协变量重要）
- **后验不确定性量化**：每个成分都有完整的后验分布
- **CausalImpact**（Google R 包）：用 BSTS 做因果推断 —— 基于干预前的数据训练模型，预测反事实（counterfactual）的干预后轨迹，实际值 vs 预测值的差异 = 因果效应

**气候科学应用潜力**：
- 量化气候政策对排放的影响
- 评估湖泊修复措施的效果
- 归因异常变暖事件

### 8.2 贝叶斯变点检测

已在之前的文档中覆盖。关键优势：可结合元数据先验（如观测站搬迁记录）提高检测 power（Beaulieu et al. 2010; Li & Lund 2015）。

## 9. 气候/湖泊科学特有考量

### 9.1 季节性的双重角色

在气候和湖泊时间序列中，季节性既是**结构**也是**信号**：
- 结构层面：必须处理（去除或显式建模）才能看到趋势
- 信号层面：季节性本身的**幅度变化**和**相位偏移**也是气候变化的指标

例如，湖泊分层提前（春季变暖更早发生）和延迟（秋季翻转推后）是比年均水温更敏感的变暖指标。

### 9.2 空间自相关

湖泊 LSWT 数据不是独立的时间序列——地理邻近的湖泊共享气候强迫。这导致：
- 简单计数「有多少湖泊显著变暖」可能高估（pseudo-replication）
- 需要空间显式模型（如 spatial GAM、空间误差模型）或多级模型

### 9.3 ERA5 数据的时间序列特殊性

froQ 使用的 ERA5 再分析数据有以下需要特别注意的属性：

- **0.25° 分辨率**（~27.8km at equator）：对大型湖泊（>100 km²）尚可，小型湖泊需要降尺度或使用 ERA5-Land（0.1°, ~9km）
- **Pixel-as-centroid 约定**：ERA5 的网格值代表格点中心的值，不是格点面积平均
- **数据同化变更**：ERA5 使用的观测系统随时间变化——1979 年前后卫星数据加入，导致某些变量的同质性断裂
- **4D-Var 框架**：ERA5 不是纯粹的观测，而是模型+观测的数据同化产物。趋势中可能混入模型偏差的变化
- **时间聚合影响**：从小时到月聚合时，聚合方式（mean/max/min）影响趋势检测。日均温使用 max+min/2 vs 24h 平均可能给出不同趋势

### 9.4 湖泊热力时间序列的特殊性

- **冰盖影响**：冬季冰盖湖泊的水温被钳制在 0-4°C，导致冬季方差极小、夏季方差大——违反同方差假设
- **缺失数据的季节性模式**：冬季/冰盖期更容易缺失数据（传感器冻结/卫星无法穿透冰层）
- **传感器迁移**：湖泊温度计的位置移动是 changepoint 检测的主要混淆因素
- **分层效应**：表层、温跃层、底层水温的趋势可能不同甚至方向相反

### 10.2 潜在扩展方向

1. **SSA/M-SSA 探索多尺度振荡**：LSWT 中可能隐藏 PDO/ENSO 的足迹，SSA 可以直接从数据中提取
2. **GAM 替代线性趋势**：当前使用 Sen's Slope 对每个湖泊估计线性趋势。GAM 可揭示趋势的非线性特征（加速 vs 减速期）
3. **小波分析验证断点**：变点检测结果是否与小波功率谱中的相位变化一致？
4. **BSTS 做归因分析**：用 BSTS 量化气候变量（气温、辐射、风速）对 LSWT 趋势的相对贡献
5. **空间层级模型**：湖泊 × 年份的多级结构 → 部分池化 → 更稳定的小湖泊趋势估计

### 10.3 Julia 时间序列生态

froQ 用 Julia 做气候数据处理。Julia 的时间序列生态（截至 2026）：

- **TimeSeries.jl**：基础时间序列类型
- **Temporal.jl**：时间索引与操作
- **StateSpaceModels.jl**：状态空间模型（含 SARIMA、ETS）
- **DSP.jl**：数字信号处理（FFT、滤波器）
- **Wavelets.jl**：小波变换
- **Loess.jl**：LOESS 平滑
- **GLM.jl + GAM (PyCall)**：GAM 需通过 RCall 调用 mgcv 或 PyCall 调用 pyGAM/pyGAM。Julia 原生 GAM 包尚不成熟

**现状**：Julia 在时间序列统计方面落后于 R（forecast/mgcv/strucchange/changepoint）和 Python（statsmodels/prophet/sktime/ruptures）。但 Julia 的计算性能优势在**全局尺度（92000 湖泊迭代）**的预处理 + STL 分解中已体现。

## 小结

时间序列分析方法论是一个四层体系：

1. **描述层**：分解（看有什么）—— STL、SSA
2. **检测层**：趋势和变点（看变了没）—— MK、GAM、changepoint methods
3. **建模层**：统计或 ML 模型（看为什么变）—— GAM+协变量、BSTS、LSTM
4. **推演层**：预测和干预（看以后怎样/如果）—— 基础模型、CausalImpact

froQ 的 hiatus 论文主要操作在 1-2 层（描述 + 检测），而 3-4 层是更深入的归因讨论（Discussion 的水文机制解释）和未来工作（量化归因、预测）的自然延伸。

本轮与前 65 轮已有的 changepoint detection（05-28）、物理机制（05-31 hiatus mechanisms）、科学图表（05-31 figure design）、IMRaD 写作五部曲形成互补，使时间序列分析的完整知识栈闭合。
