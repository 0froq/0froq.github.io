# CSS 与 Web 平台 2026：该关注什么

2026-05-30 巡检整理

CSS 近两年的变化超过此前十年。容器查询、原生嵌套、`:has()`、滚动驱动动画、View Transitions 已稳定跨浏览器，覆盖 94%+ 用户。

---

## 已可投入生产

### Container Queries（容器查询）

组件不再依据 viewport 宽度响应，而是依据自己的容器宽度。一个 card 组件放在主内容区、侧边栏、弹窗里都能自动适配，不再需要 variant props 和 JS 判断。

```css
.card-wrapper { container-type: inline-size; }
@container (min-width: 500px) { .card { grid-template-columns: 200px 1fr; } }
```

新增容器查询单位：`cqi`、`cqw`、`cqh` 等，适合组件内流体排版。

**支持**：Chrome 105+ / Firefox 110+ / Safari 16+ / Edge 105+

### CSS Nesting（原生嵌套）

```css
.nav {
  background: var(--color-surface);
  ul { display: flex; gap: 1rem; }
  a {
    color: var(--color-text);
    &:hover { color: var(--color-primary); }
  }
}
```

自 2024 年末起，Chrome/Firefox/Safari 中元素选择器不再需要 `&` 前缀。如果只用 Sass 做嵌套和变量，可以去掉预处理器了。

### `:has()`（父选择器）

比传统「父选择器」更强大，支持后代、兄弟、状态组合：

```css
/* 含图片的 card 自动切换布局 */
.card:has(img) { grid-template-rows: 200px 1fr; }

/* 表单校验：输入框有焦点时移动 label */
.form-group:has(input:focus) label { color: var(--color-primary); transform: translateY(-24px) scale(0.85); }

/* 纯 CSS 禁用提交按钮（任一必填为空时） */
form:has(input:required:placeholder-shown) button[type="submit"] { opacity: 0.5; pointer-events: none; }
```

可替代大量切换 parent class 的 JS 代码。

### Scroll-Driven Animations（滚动驱动动画）

动画时间轴不再绑定时钟，而是绑定滚动进度。无需 JS 滚动监听和动画库。配合 View Transitions 可实现沉浸式叙事页面。

**支持率**：83-85%，建议作为渐进增强使用。

### View Transitions API

单页应用页面切换动画，原生实现，不依赖路由库。Same-document View Transitions 已纳入 Interop 2026 深化打磨。

### `color-mix()` + `oklch()` 色彩体系

```css
:root {
  --primary: oklch(0.6 0.2 250);
  --primary-light: color-mix(in oklch, var(--primary), white 30%);
  --primary-dark: color-mix(in oklch, var(--primary), black 20%);
}
```

用少量自定义属性派生完整调色板，替代手工维护几十个色值。

## Interop 2026 重点方向

Interop 2026 共 20 个焦点领域（来自 33 项开发者提案），CSS 相关亮点：

| 特性 | 说明 |
|------|------|
| **CSS Anchor Positioning** | 元素根据另一元素定位（如 tooltip 跟随引用内容）。Interop 2025 延续项，2026 着重打磨边缘情况一致性 |
| **Container Style Queries** | 不仅查容器尺寸，还能查样式值：`@container style(--theme: dark)` |
| **`contrast-color()`** | 自动根据背景色返回黑或白的前景色 |
| **`attr()` 增强** | `attr(data-color type(<color>))` — 可从 HTML 属性读取带类型的值 |
| **`shape()`** | 用 CSS 绘制任意形状（替代 clip-path 的 SVG 依赖） |
| **Custom Highlights** | `::search-text`、`::spelling-error`、`::grammar-error` 等伪元素 |
| **CSS `zoom`** | 标准化 zoom 属性行为 |
| **Scroll Snap** | 深化 scroll snap 跨浏览器一致性 |
| **Dialogs & Popovers** | `<dialog>` 和 Popover API 互操作打磨 |

## 对 Vue.js 开发者的影响

1. **可以开始考虑去掉 Sass/SCSS**：如果只用嵌套和变量，原生 CSS 已覆盖。PostCSS 仍可用于未来的语法降级。
2. **组件响应式逻辑可下沉到 CSS**：Container Queries 替代 variant props，`:has()` 替代父级 class 切换逻辑。
3. **动画库减负**：滚动驱动动画 + View Transitions 可替代 GSAP ScrollTrigger / 部分 Framer Motion 场景。
4. **Anchor Positioning 值得关注**：Interop 2026 推进后，dropdown/tooltip/popover 的定位逻辑可以完全从 JS 移到 CSS。
